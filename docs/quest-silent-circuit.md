# 《零域协议》可交互探索剧情：静默回路

> 文档状态：待确认  
> 预计时长：10–15 分钟  
> 使用场景：SITE OMEGA 指挥中心、B7 收容区  
> 主要角色：凌霁（LYRA-7）、沈砚、Sentinel

## 1. 设计目标

- 玩家在安全区接受任务，通过探索获得战术信息，然后进入 B7 完成战斗并返回汇报。
- 至少包含 3 次场景互动和 1 次会影响战斗与结局的选择。
- 让凌霁在“降低当前威胁”和“冒险保留真相”之间做决定。
- 只使用现有场景、角色和战斗系统，不扩展大型支线或背包系统。

## 2. 流程概览

| 阶段 | 内容 | 预计时间 |
|---|---|---:|
| 1. 接令 | 与沈砚对话，接受调查 B7 的任务 | 1–2 分钟 |
| 2. 战前准备 | 读取安全终端，选择一次战术补给 | 2–3 分钟 |
| 3. 进入 B7 | 乘电梯进入收容区，找到损坏的控制中继 | 1–2 分钟 |
| 4. 风险选择 | 切断供能降低难度，或镜像握手保留证据 | 1 分钟 |
| 5. 战斗 | 根据终端情报，利用防御和反击击败 Sentinel | 3–5 分钟 |
| 6. 回收与汇报 | 调查残骸，返回指挥中心交付任务 | 2 分钟 |

```text
未接取 → 已接取 → 已读取终端 → 已进入 B7
       → 已选择中继方案 → 战斗中 → 已击败
       → 已回收记录 → 已完成
```

## 3. 剧情节点

### N0：沈砚——任务简报

**触发：** 初始状态靠近沈砚，按 `E`。

**沈砚：**

> B7 的巡逻节点在六分钟前脱离控制。一台 Sentinel 封锁了收容区，而且它正在使用你的识别码申请核心权限。

**玩家选项：**

1. **「我的识别码为什么会出现在 B7？」**
   - 沈砚：“最后一份完整记录还在安全终端。先看记录，再下去；我不想让你对着另一个‘自己’开火。”
   - 返回选项列表，不改变状态。
2. **「任务目标？」**
   - 沈砚：“终止 Sentinel，回收它的最后一次认证记录，然后回来汇报。B7 的控制中继也许能削弱它，但那会损坏证据。”
   - `quest_state = ACCEPTED`
   - HUD 目标：`读取指挥中心安全终端`。

**重复互动：**

> 先检查安全终端，再使用东侧电梯进入 B7。

---

### N1：安全终端——读取战术记录（必做）

**条件：** `quest_state == ACCEPTED`。

**终端：**

> B7-7A 最终记录：Sentinel 每完成两次常规攻击后，将执行一次高功率破障攻击。控制中继仍可接受本地维护指令。

**选项：「下载战术记录」**

- `quest_state = TERMINAL_SCANNED`
- 战斗教程解锁：`敌方每第 3 次行动发动重击；提前防御可形成反击窗口。`
- 电梯解锁。
- HUD 目标：`整备后乘电梯前往 B7`。

---

### N2：应急补给箱——单次整备（可选）

**条件：** 任务已接取，且 `supply_choice == NONE`。

**系统：**

> 箱内仅剩一组可用接口。选择后，另一组将因安全锁失效。

| 选项 | 效果 | 反馈 |
|---|---|---|
| 接入医疗凝胶 | HP `+140`，不超过上限 | 外骨骼密封层已修复 |
| 接入过载电池 | MP `+120`，不超过上限 | NEX-4 备用电容已充能 |
| 暂不使用 | 不改变变量 | 可以稍后再选 |

领取后再次互动：`补给箱已清空。`

---

### N3：指挥中心电梯

**未读取终端：**

> B7 导航协议缺失。请先读取安全终端的最后记录。

**已读取终端：**

> 目的地：B7-7A 收容区。检测到敌对自动单位。

- **「进入 B7」**：`quest_state = IN_B7`，切换至 B7。
- **「返回整备」**：关闭对话，不改变状态。

---

### N4：损坏的控制中继——关键选择（必做）

**系统：**

> 中继仍在转发 LYRA-7 认证握手。可切断区域供能，或镜像握手并保留完整来源记录。选择一经执行不可撤回。

#### 选项 A：切断供能，优先降低威胁

- `relay_choice = CUT_POWER`
- Sentinel 最大 HP：`170`。
- Sentinel 伤害倍率：`0.9`。
- `evidence_intact = false`。
- 中继熄灭，场景稍微变暗。
- 反馈：`供能下降。Sentinel 装甲响应明显减弱，但认证缓存正在丢失。`

#### 选项 B：镜像握手，保留完整证据

- `relay_choice = MIRROR_SIGNAL`
- Sentinel 最大 HP：`220`。
- Sentinel 伤害倍率：`1.0`。
- `evidence_intact = true`。
- 反馈：`握手镜像建立。Sentinel 尚未察觉中继被监听。`

**共同后果：**

- `quest_state = RELAY_DECIDED`。
- Sentinel 变为可交互目标。
- HUD 目标：`接近并终止 Sentinel`。
- 中继无法重复选择，防止反复切换战斗难度。

---

### N5：Sentinel——战斗入口

**Sentinel：**

> 身份冲突。检测到两个 LYRA-7 神经签名。执行收容协议。

- **「进入战斗」**：打开回合制战斗界面，冻结探索移动。
- **「后退」**：关闭对话，保留当前状态。

#### 本任务所需的战斗规则

- 玩家先手。
- `脉冲斩击`：34–42 伤害。
- `过载突袭`：68–80 伤害，消耗 60 MP。
- `战术防御`：本回合受到的伤害降至 35%。
- `撤离`：返回 B7；保留当前 HP/MP，Sentinel HP 重置。
- Sentinel 每第 3 次行动发动 1.75 倍重击。
- Sentinel HP 低于 50% 后，攻击乘以 1.25。
- 玩家用防御挡住重击后，下一次攻击伤害乘以 1.75，并显示`反击窗口`。

#### 战斗结果

- **胜利**：`quest_state = SENTINEL_DEFEATED`，返回 B7，Sentinel 替换为可调查残骸。
- **失败**：凌霁被 K-12 紧急回收至指挥中心；HP 恢复至上限的 35%，Sentinel 重置，中继选择保留。

---

### N6：Sentinel 残骸——回收记录（必做）

#### 完整证据路线

> 认证记录完整。伪造的 LYRA-7 握手并非来自 B7，而是由核心区下方反向注入。记录末尾只有一行：`欢迎回来。`

- `record_recovered = FULL`。

#### 部分证据路线

> 认证缓存已严重损坏。仅能确认指令来自基地更深层，发送者身份无法恢复。

- `record_recovered = PARTIAL`。

**共同后果：**

- `quest_state = RECORD_RECOVERED`。
- HUD 目标：`乘电梯返回指挥中心，向沈砚汇报`。

---

### N7：电梯——返回指挥中心

- 允许玩家随时返回指挥中心。
- 如果未回收记录，沈砚不会结算，HUD 仍提示玩家返回 B7。

---

### N8：沈砚——汇报与结算

#### 结局 A：威胁已隔离

**凌霁：**

> Sentinel 已停机，但中继断电毁掉了大部分认证缓存。只能确认信号来自基地更深处。

**沈砚：**

> 你先控制住了眼前的威胁，这个决定没有错。但从现在开始，我们得假设下面还有一个东西能复制你的身份。

- 结局标题：`静默回路 · 威胁已隔离`
- 奖励：`+240 CR`、`+200 EXP`。

#### 结局 B：信号已追踪

**凌霁：**

> 记录保住了。伪造握手来自核心区下方，而且发送者知道我会回来。

**沈砚：**

> 把记录从基地网络隔离。凌霁，在我们确认那句话的接收对象之前，不要再让任何系统读取你的神经签名。

- 结局标题：`静默回路 · 信号已追踪`
- 奖励：`+320 CR`、`+250 EXP`。
- 新增日志：`异常握手源头：核心区下方。`

**共同后果：**

- `quest_state = COMPLETE`。
- 奖励只能发放一次。
- HUD 显示：`任务完成：静默回路`。

## 4. RPG 成长与迷宫扩展

### 4.1 普通怪物与练级

B7 不再只有 Sentinel，而是放置 3 类地图上可见的敌人。玩家可以观察巡逻路线并选择是否接敌，不使用随机踩雷。

| 怪物 | 定位 | 战斗特点 | EXP | 可能掉落 |
|---|---|---|---:|---|
| 维修爬行者 | 教程怪 | HP 低，用于熟悉攻击和防御 | 90 | 少量 CR、恢复剂 |
| 脉冲猎犬 | 高速怪 | 首回合较快，但防御较低 | 130 | 电容芯片 |
| 护盾无人机 | 防御怪 | 会生成一回合护盾，鼓励使用技能 | 170 | 装备材料 |

- 主角初始为 `Lv.3`，B7 的首批怪物经验足以让玩家在 Sentinel 战前或战后升到 `Lv.4`。
- 普通怪被击败后在本次任务中不刷新，避免被迫反复刷怪。
- 任务完成后可解锁“B7 训练协议”，作为后续可重复练级入口。

### 4.2 等级与升级收益

| 升级收益 | 数值 |
|---|---:|
| 最大 HP | `+60` |
| 最大 MP | `+35` |
| 基础攻击 | `+4` |
| 技能点 | `+1` |

- 升级时回复 30% HP 和 MP，用作清晰的成长反馈。
- 首版等级上限先设为 `Lv.8`，不做复杂职业树。

### 4.3 技能与 MP

| 技能 | 解锁 | MP | 效果 |
|---|---:|---:|---|
| 脉冲斩击 | 初始 | 0 | 34–42 伤害，基础攻击 |
| 量子贯穿 | Lv.4 | 45 | 72–86 伤害，忽略 30% 护甲 |
| 过载突袭 | Lv.5 | 70 | 105–125 伤害，使用后下回合受伤 +15% |
| 零域干扰 | Lv.6 | 60 | 中等伤害，降低敌人下一次攻击 35% |

- 高伤害技能必须消耗 MP，MP 不足时按钮置灰并显示差额。
- 普通攻击不消耗 MP，成功防御可回复 12 MP，避免战斗陷入无法行动的状态。
- 升级获得的技能点只用于解锁或强化技能，暂不增加复杂属性加点。

### 4.4 装备与宝箱

首版只保留 3 个装备位，保证玩家能立即理解掉落价值。

| 装备位 | 主要属性 | B7 宝箱示例 |
|---|---|---|
| 武器模组 | 攻击、技能伤害 | `NEX-4 谐振刃`：攻击 +8 |
| 外骨骼 | HP、防御 | `B7 维护装甲`：最大 HP +90 |
| 能量核心 | MP、MP 回复 | `静默电容`：最大 MP +45 |

- 怪物只掉落消耗品和材料；完整装备主要通过宝箱、谜题和任务获得。
- 宝箱会显示装备对比，由玩家选择“立即装备”或“收入仓库”。
- 首版不加随机词条、装备强化或耐久度。

### 4.5 B7 维护迷宫与解密宝箱

在通往 Sentinel 的主路旁设置一个小型可选维护区，建议为 6–8 个房间，而不是大型随机迷宫。

**谜题：三段脉冲锁**

1. 入口终端显示三段波形：`短 → 长 → 短`。
2. 迷宫内有 3 座维护节点，分别发出不同长度的灯光脉冲。
3. 玩家需要按正确顺序激活节点。
4. 顺序错误时不立即失败：首次错误只重置，第二次错误会唤醒一只护盾无人机。
5. 成功后开启宝箱，获得 3 件 B7 装备中的 1 件。

**两种任务路线的影响：**

- `CUT_POWER`：迷宫内部分门失去供电，路线更短，脉冲灯提示更明显。
- `MIRROR_SIGNAL`：保留全部安全系统，路线更长且多一只巡逻怪，但宝箱额外附带 `+60 CR`。
- 两条路线都能获得完整装备，不让保守选择永久错过成长内容。

### 4.6 首个可玩成长循环

```text
探索 B7 → 发现可见怪物 → 战斗获得 EXP / 材料
       → 升级获得技能 → 解谜开启宝箱
       → 换上装备 → 挑战 Sentinel → 回收记录
```

## 5. 变量表

| 变量 | 类型 / 默认值 | 用途 |
|---|---|---|
| `quest_state` | enum / `NOT_STARTED` | 任务主状态机 |
| `supply_choice` | enum / `NONE` | `NONE / MED_GEL / BATTERY` |
| `relay_choice` | enum / `NONE` | `NONE / CUT_POWER / MIRROR_SIGNAL` |
| `record_recovered` | enum / `NONE` | `NONE / PARTIAL / FULL` |
| `reward_claimed` | bool / `false` | 防止重复领取任务奖励 |
| `player_hp` | int / `860` | 在探索与战斗间保留 |
| `player_energy` | int / `420` | 在探索与战斗间保留 |
| `credits` | int / `480` | 任务奖励 |
| `experience` | int / `1840` | 任务奖励 |

`terminal_scanned`、`sentinel_defeated`和`evidence_intact`建议优先由上述枚举状态推导，避免多个布尔值互相矛盾。

## 6. 路线对比

| 路线 | 战斗难度 | 情报结果 | 奖励 | 结局语气 |
|---|---|---|---|---|
| 切断供能 | 较低：170 HP、伤害 ×0.9 | 部分记录 | 240 CR、200 EXP | 安全，但留下疑问 |
| 镜像握手 | 标准：220 HP、标准伤害 | 完整记录 | 320 CR、250 EXP | 风险换来明确线索 |

## 7. Godot 实现约束

- 任务变量统一保存在 `GameState` Autoload，不在场景中重复保存。
- 任务阶段使用 `enum QuestState`。
- 指挥中心和 B7 可保持在同一探索脚本内切换背景，也可拆分场景；本轮优先选择改动更小的方案。
- 对话先用数据字典或 `match quest_state`，暂不引入复杂对话插件。
- 战斗开启时冻结探索输入；敌方行动结束前锁定战斗按钮。
- Sentinel 胜利后切换为残骸互动，奖励结算前必须先回收记录。
- 撤离或失败后保留 `relay_choice`，不允许为了改难度重新选择。
