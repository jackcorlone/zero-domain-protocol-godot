# 《镜后回声》：闻缄幻境与控魂战 v0.1

日期：2026-09-05。承接《红钻清算》。本章目标是在裘盛赌局后快速换挡：从公开的财富清算转入私密空间中的精神入侵，再由凌霁主动反定位、登舰并在闻缄最擅长的控制领域击败他。

## 章节流程

1. 裘盛试图启动逃生门，但托管系统锁死出口；执法人员依据冻结令将其带走。
2. 玩家返回基地，完成赌场结算。当天夜里，凌霁在私人卧室洗漱后的镜前发现影像慢半拍。
3. 闻缄的虚影在镜中出现：“你以为赢走的是他的钱？你只是替我拆掉了最后一道锁。下一次，你连自己在害怕什么都分不清。”
4. 凌霁回应：“那你最好藏严一点。你已经留下回声了。”卧室被覆盖为亡者幻境。
5. 玩家识别三处现实锚点，恢复清明值并从入侵载波反向定位闻缄的“蜃心中继舰”。
6. 凌霁主动乘飞船追踪，依次清理静默甲板、回声舱与两根精神导管，进入控魂中枢。
7. RPG首领战允许闻缄连续控制，但给出预警、挣脱、净化和两回合硬上限。凌霁最终让魂丝回灌，锁住闻缄自己的控制核心。

## 卧室幻境

帮助凌霁的是基地配发的“澄明手环”，不是已交给执法部门取证的赌场负债环。手环只能显示可信的心率、真实时间和外界信号，不能自动破解幻境。

幻境依次出现凌霁已经失去的朋友与家人。他们保留熟悉的外貌，不展示死亡过程，也不以惊吓画面消费她的创伤。他们会用错误归责、劝她留下或要求她放弃仍活着的人。凌霁一度濒临情绪失控，但胜利不是“毫无悲伤”，而是承认思念并辨认真伪：

> 我当然想念你们。但真正的你们，不会让我放弃还活着的人。

三个现实锚点分别是：手环心跳与镜像动作不同步；幻影说出违背本人价值观的话；窗外星图左右颠倒。当前原型将它们实现为按顺序选择的三步校验；短方向键呼吸节奏与清明值表现仍属于后续增强。选择错误会重置校验顺序，不进入精神崩坏BE。

## 赌局输入机制

### 第一局：暗仓竞价

连续输入五个四方向提示。剧情结果固定为败北，但界面提前说明真正目标是“保持冷静并读取担保签名”，避免伪装成可赢的选择。准确输入积累冷静值，表现好可提前显示一枚签名碎片；失误只改变裘盛的嘲讽和凌霁的回应。

### 第二局：真假契据

使用三枚资产骰，玩家最多掷三次，每次可锁定一枚并重掷其余骰子。目标组合为“同一资产＋双重抵押＋资金出口”；第一局积累的冷静值可将一枚骰子调整一面。失败保留已经发现的线索并立即重试，不重复长对白。

### 第三局：万藏归一

前半再次使用更快的方向键序列。筹码仍持续倾向裘盛，输入准确度实际填充隐藏的审计链。后半将“受益人密钥＋披露权＋受害者签名”组成证据骰；前两次只验证签名真假，第三次改问资产来源是否合法，完成最终反转。连续失误三次后高亮下一条有效证据，不软锁主线。

## 登舰清兵

- 静默甲板：当前实现第一场160 HP警戒战，表现关闭入口干扰器。
- 回声舱：当前实现第二场190 HP幻影守卫战，通过后开放控魂中枢。
- 控魂中枢：精神导管削弱与真假目标手环脉冲仍属于后续增强；当前两场警戒战使用现有敌人图作为临时素材。

## 闻缄首领战

当前可玩版不另起一套资源条，而是把澄明手环接入现有防御指令。闻缄施放控魂前，HUD、战斗日志和防御按钮会同时出现“紫色裂纹”预警。此时选择【锚定现实】，可以阻断本次控魂、获得两回合“坚定”，并开启反击窗口。

如果玩家选择抢攻，控魂命中率为40%，紧接着的第二次为20%。连续失控硬上限是两回合；第二次成功后，闻缄的魂丝过载并丢失下一次行动，凌霁同样获得反击窗口与两回合坚定。第三次连续禁行动永远不会发生。

独立的清明值、心痕/魂丝资源条、亡者台词选择和方向键意志检定属于后续深化，不虚报为已完成。

首领三阶段：

1. 100%—66%“镜语试探”：每三回合出现控魂预警，教授玩家锚定现实。
2. 66%—33%“亡者回声”：预警加快为每两回合，在日志中继续用伪造记忆施压。
3. 33%—0%“反噬核心”：每回合准备控魂。玩家可稳健锚定，也可承受可预判风险，在第二次失控后利用魂丝过载反击。

进入闻缄战前会建立安全存档。战败后触发三幕 **BAD END《借来的声音》**：第一幕中，闻缄沿双向链路盗用凌霁的身份签名，向蓝星联合防线发送伪造撤防指令；第二幕中，凌霁被关入葬潮号深层隔离舱，但仍在利用澄明手环记录门锁周期；终幕中，三首领以军事威慑、认证劫持和资金网络形成闭环，夺取蓝星星核并控制跨星域舰队。这是技术性强迫和身份盗用，不是凌霁同意、堕落或改变阵营。前两幕只能继续观看，终幕才可读取进入千声室前的最近安全存档；整段 BE 不写入进度。
