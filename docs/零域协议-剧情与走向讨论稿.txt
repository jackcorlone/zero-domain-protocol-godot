==================================================
一、游戏核心方向
==================================================

玩家扮演成年女性凌霁（LYRA-7），以 SITE OMEGA 为据点，由主线任务逐步开放新地区。每个地区都应包含一段身份谜团、一组可自由排序的调查点、至少一种战斗替代方案、会改变局部世界状态的选择，以及返回基地汇报的闭环。

主线悬念：有人能伪造凌霁的神经签名，并利用早于她现有记忆的旧协议控制设施。线索逐步推进：

伪造的 LYRA-7 身份
→ 三年前的 LYRA-7 返航申请
→ 无人驾驶机体中的“同步对象：LYRA-7”
→ “LYRA-0 / DRIVER ABSENT”
→ SITE OMEGA 核心区隐藏的零号协议

核心主题不是只问“凌霁是不是原版”，而是：当制度、机器和他人都试图用旧身份定义她时，她是否仍能决定自己是谁、相信谁，并选择愿意为真相支付什么代价。

设计原则：

1. 主线任务推动地区开放，不靠菜单直接选择章节。
2. 探索顺序与解决方式由玩家决定，战斗不是唯一答案。
3. 选择改变情报、敌情、NPC 关系及结局语境，但不制造无提示软锁。
4. 支线可以与主线交汇，拒绝任一支线都不阻断主线通关。
5. 装备、情报、关系和同意分别记录，不用隐藏数值替玩家决定关系。

==================================================
二、当前可玩的剧情
==================================================

【已实现】第一章：静默回路

地点：SITE OMEGA 指挥中心、B7 收容区。

B7 的 Sentinel 脱离控制，并使用凌霁的识别码申请核心权限。沈砚要求凌霁读取安全终端，再进入 B7 调查。玩家可领取一次医疗或能量补给，并在控制中继处作出不可重复的战术决定：

1. 切断供能：降低 Sentinel 的生命与伤害，但损坏部分认证记录。
2. 镜像握手：保留完整来源证据，但面对完整战力。

击败 Sentinel、回收残骸并返回汇报后，部分记录只能确认信号来自基地更深处；完整记录则确认握手由核心区下方反向注入，末尾留言为“欢迎回来”。两条路线都能完成任务，保留完整证据会获得更多奖励。

【已实现】B7 维护支路与成长内容

玩家可自行探索，或向罗茂购买坐标，发现 B7 南侧维护支路。支路包含额外警戒、机关、装备与私人供货记录。记录只显示试制件未经过公库审批、罗茂是担保人，去向写着“确保凌霁安全返航”。它留下疑点，但不会在故事前段直接证明罗茂别有用心。

【已实现】第二章：回声之外

地点：H1 飞船舱、ECHO-9 灰潮盆地、断讯高地、坠毁货船、裂隙栈道、废弃观测站。

完成《静默回路》后，基地外一个被删除的冰原坐标回应凌霁的识别码。玩家乘“游隼”前往灰潮盆地，在三条支路中任取两份定位线索，即可核验观测站。支路可任意顺序调查：

断讯高地：读取天线记录，可决定是否恢复灯标。
坠毁货船：读取运输清单，可决定是否救出受困维修员。
裂隙栈道：取得工程记录，可修桥并寻找测绘模块。

观测站可通过正门战斗、维护口解谜或身份核验进入。最终档案显示：“LYRA-7 的返航请求已获批准。”时间戳是三年前，发送地点却是 SITE OMEGA。玩家可保留信标继续追踪，或复制档案后关闭信标。两种处置基础奖励相同，结算后仍能重返地区。

【部分实现】M2 天穹校验坪

现版本已有科幻平地 RPG 地图、赤线炽天驾驶、白曜神盾独立单位、铁垒巡逻敌机、接触提示与基地入口。《空白驾驶员》的完整任务状态、选择、战斗、残骸回收和汇报闭环仍属于后续补完项。

【已实现前段】罗老板支线

玩家当前看到的罗茂和气、热心，近乎人畜无害。他与凌霁原本只有同事关系，却格外关心她能否安全返航；他动用旧关系送出高输出、高风险的“赤线”战术服、电池和维护路线，并逐渐透露自己做过非公开运输担保的秘密。编剧层面的真相是：这些好意并不真诚，而是他为了取得凌霁信任、逐步索取亲密关系所做的长期投入。当前版本只呈现伪善外表，还没有实现亲吻、越界证据和最终决裂。

三、建议的主线章节与地区走向
==================================================

第三章：空白驾驶员
地区：M2 天穹校验坪
状态：【建议优先补完】

M2 收到时间戳来自三年前的驾驶员上线请求。白曜驾驶舱内无人，却报告与 LYRA-7 完成神经同步；铁垒被旧协议远程唤醒。玩家驾驶赤线炽天调查电容站、物流终端和白曜，再面对北侧校验塔守卫。

白曜处提供明确二选一：

隔离启动：降低最终战斗风险，只取得静态记录。
镜像同步：提高风险，但取得完整握手。

完整线索为“LYRA-0 / DRIVER ABSENT”。本章只证明旧协议将凌霁视为缺失驾驶员的替代对象，不立即确认克隆、时间穿越或记忆移植。任务完成后开放 C9。

第四章：封锁区 C9
地区：工业交通环、封锁走廊、陷阱控制室、转运站
状态：【规划建议】

敌对组织利用零号协议重启封锁设备，并转移人员与旧档案。本区引入可见巡逻、先手/伏击、激光拌线、磁性地板、泡沫喷口、电击通风口及多条维修通道；中途撤回基地时保留调查进度。

主线目标是取得转运记录并恢复通往 B2 的权限。凌霁闺蜜的失踪在此被发现，但作为独立支线记录，不强绑 C9 主任务结算。

第五章：B2 审讯区
地区：拘留环、医疗观察室、审讯档案库
状态：【规划建议】

被捕人员正被筛选是否能充当旧协议的“身份见证者”。敌人试图借熟悉凌霁的人校验她的记忆和行为。玩家可推进闺蜜营救，也能只完成主线档案回收。档案揭示旧 LYRA 项目不是单台机体实验，而是一套把身份权限分散到基地、机体和见证人身上的协议。本章结束后取得 LEVEL 06 的路径。

第六章：零号井
地区：核心区下层、神经档案库、原型机控制井
状态：【规划建议】

基地核心将凌霁识别为“LYRA-0 的连续性载体”，要求她恢复旧权限。沈砚主张先隔离核心，敌对组织希望重启协议。罗茂线的证据可揭示一条被滥用的后勤权限链，但已经决裂的罗茂不再作为终章盟友，也不以交出情报换取原谅。

最终选择回答的不是“你是不是原版”，而是：是否接受旧身份赋予的权限，是否公开真相，是否把控制权交给基地，以及是否销毁仍能复制她的协议。主线通关不要求接受罗茂的亲密要求或在决裂后重新联系他。

四、支线一：被俘的好闺蜜
==================================================

角色暂定：优先使用现有角色“苏棠”，但姓名、职业和关系尚待确认。建议将她设为熟悉旧基地通信或医疗记录的技术人员。敌人抓她是为了验证凌霁的身份记忆，而不是随机绑架。

苏棠不能只是等待营救的任务物品。她在被捕期间应主动留下加密线索、误导审讯者并争取逃脱窗口；获救后也有权决定是否继续反追踪。

第一阶段：失联

进入 C9 后发现苏棠的私人识别片段与被篡改的转运名单。玩家可立即追查、先完成地区主线、交给沈砚共同核验或暂时不接。延后不会无提示导致她死亡，只会改变入口、敌人布置和对话。

第二阶段：追踪与接近

正面突破：战斗多，最快接触目标。
伪造转运权限：需要主线档案或探索证件，战斗较少。
维护通道：要求充分地区探索，包含机关。
灰色情报：可与罗茂交易，但不是唯一入口。

接触苏棠后，可立即撤离、植入追踪标记后组织安全营救，或与她共同制定方案。若让她继续暴露，必须得到她的明确同意，界面也要提前显示风险。

第三阶段：营救与余波

安全归队：她回基地提供通讯支援，关系更重视互信。
共同反追踪：她自愿协助追查抓捕者，开放额外核心区情报，但敌方警戒提高。
关系受损但可修复：若凌霁隐瞒风险或擅自替她决定，她会表达不满；后续可通过坦白与行动修复，不用隐藏好感值突然判坏结局。

奖励以新区域信息、通讯协助或探索能力为主，不把苏棠本人当作奖励。

==================================================
五、支线二：罗老板的伪善与决裂线
==================================================

人物定性：罗茂是明确的反派，不是道德灰色人物。他外表和气，平时愿意替同事处理麻烦，在基地里拥有“老好人”的名声。凌霁最初认为他没有危险性，两人也只有普通同事关系。

罗茂最初因凌霁出众的外形与身材产生欲望。他把“和凌霁在一起”理解为最终应当占有她，包括得到她的身体。为了达到这个目的，他刻意扮演体贴可靠的同事，把装备、情报、关心和所谓秘密都当成取得信任的投资。帮助产生的实际效果是真的，善意却是装出来的。

玩家前期和凌霁看到的是罗茂精心设计的表象；只有编剧文档和后期证据确认他的真实动机。故事不把他解释成“爱得方式不对”，而是明确指出：他在利用善良的外观操纵他人的选择。

第一阶段：人畜无害的同事【前半已实现】

罗茂先关心凌霁任务中有没有受伤，再把通过旧关系取得的赤线、电池和维护路线交给她。他暂时不索取回报，只说这些东西放在仓库里没有意义，希望她能安全回来。实际上，他在观察凌霁会接受多少帮助，并等待她把安全、信任和自己联系起来。装备确实强力；拒绝仍不影响主线补给。

第二阶段：分享秘密与建立信任【规划建议】

随着任务推进，罗茂告诉凌霁自己曾替非公开运输线做担保，也认识能绕开旧封锁的人。他故意挑选一部分不会真正伤及自己的秘密，让凌霁产生“他只信任我”的感觉，同时继续提供能缩短 C9 或 B2 调查路线的情报。完整真相始终被他扣在手里。

罗茂邀请凌霁在任务后吃饭。玩家可以拒绝、只在公共场所见面，或选择进一步了解他。无论选择如何，已经赠送的装备都不会被收回。

第三阶段：短暂的亲密【规划建议】

若凌霁选择靠近，两人在一次危险任务结束后单独交谈。凌霁相信罗茂一直真心保护自己，明确愿意接受这一次亲吻和拥抱；不以沉默代替她的答复。她在当时作出的选择是真实的，却建立在罗茂蓄意制造的错误印象上。

罗茂把这次亲密错误地理解为自己的投入开始得到回报，并妄想借装备、信息和情感债继续推进关系，最终得到凌霁的身体。过去的亲吻与拥抱不代表凌霁同意任何后续接触；玩家若此前拒绝靠近，仍能推进主线和后续调查。

第四阶段：看不见的越界【规划建议】

在表面关系改善期间，罗茂已经开始秘密侵犯凌霁的边界：

1. 利用后勤权限读取她的私人训练排程与身体状态数据。
2. 在凌霁进行非公开训练时躲在观察区观看她，而她并不知道。
3. 以检查装备或送补给为借口，未经允许进入她的私人舱室。
4. 保存本不需要留存的门禁、休息和训练记录，用来判断何时最容易单独接近她。
5. 扣下部分任务信息，让自己总能在关键时刻提供帮助，从而继续维持“只有我最可靠”的形象。

这些行为通过门禁日志、权限查询、被移动的物品和前后矛盾的口供表现。镜头不展示凌霁的身体作为福利，不把偷窥或擅入房间拍成浪漫桥段；叙事重点是欺骗、监视和权限滥用。

第五阶段：筹码与真相暴露【规划建议】

当罗茂认为关系已经足够深入，他开始提起自己送出的装备和提供的情报，暗示凌霁应该给予更进一步的身体亲密作为回应。他仍用关心的语气包装要求，并把拒绝描述成凌霁“不相信他”或“把他的好心当成利用”。

凌霁随后取得完整权限记录，发现所谓偶遇、及时援助和秘密分享大多经过安排。罗茂并非偶然越界，而是从最初就把善意当作投资，把凌霁当作预期回报。

第六阶段：纠结与决裂【规划建议】

凌霁先质问罗茂。罗茂不真正认错，而是辩称自己“从未伤害她”“做的一切都是为了她”，并把送出的装备、情报和两人曾经的亲密当作自己拥有资格的证明。凌霁会想起自己接受过的帮助、亲吻和拥抱，短暂怀疑是否因为没有更早拒绝才造成这一切。

她最终意识到，自己是在被欺骗的前提下信任他；过去没有拒绝，不等于允许罗茂继续索取，也不需要为他的越界负责。她主动结束这段关系：

“我以为你是在帮我。原来你只是在计算，要付出多少东西，才能把我变成你的。”

“我相信过你，也吻过你。但那不是一张让你继续进入我生活、碰我的身体的通行证。”

决裂是这条私人关系的确定结局。玩家仍可决定：公开全部证据；只上交涉及受害者的部分；保留或退还合法获得的装备；关闭全部联络，或仅保留受监督的任务通讯。这些选择影响罗茂的后续处境，但不会改变凌霁已经结束私人感情的决定。

==================================================
六、两条支线与主线的交汇
==================================================

1. C9 路线：罗茂能提供捷径；苏棠线也能通过独立探索找到入口。罗茂只节省时间，不垄断营救。
2. B2 供货名单：苏棠掌握审讯设备使用记录，罗茂的私人供货记录指向设备承包链。它证明他的渠道间接参与过敌方物流，但罗茂不是绑架主谋。
3. 是否公开证据：决裂后，玩家可全部提交，或只提交涉及受害者与任务安全的部分。若证据涉及苏棠，她必须拥有发言权。
4. 终章主题：沈砚代表受监督的秩序；苏棠代表私人信任与共同选择；罗茂代表把伪善包装成爱、把帮助变成筹码的控制欲；零号协议代表以身份连续性之名剥夺自我定义权的系统。

==================================================
七、结局方向
==================================================

自我命名：公开零号协议，拒绝被定义为旧驾驶员的替代品。

受控继承：接受部分旧权限，但把协议置于多人监督之下。

关系余波：罗茂线完成后，凌霁不会与他复合，也不会把他的行为解释成深情。根据证据处置，罗茂可能被停职调查、撤销后勤权限或移交纪律审查；凌霁与他的私人感情均已结束。

静默封存：销毁可复制身份的协议，放弃追查部分过去；短期威胁最低，但真相永久残缺。

苏棠支线作为结局修饰：互信状态下她参与最终行动；关系疏离时仍反对敌方协议但不再无条件信任凌霁；共同反追踪可提供隐藏档案；未完成则保留“去向未明”的遗憾，不无提示判定死亡。

八、建议实现顺序
==================================================

1. 统一主线、苏棠线、罗茂线和地区世界状态；验证旧存档都有默认值。
2. 补完 M2《空白驾驶员》；验证准备、二选一、守卫战、残骸和汇报形成闭环。
3. 建立通用角色立绘对话框；验证发言人、姓名、立绘、选项与无立绘回退。
4. 制作 C9 第一张地图；先验证巡逻、伏击、陷阱、撤回和存档，不一次塞入全部剧情。
