# 罗茂支线：伪善与决裂·基地前置篇

版本：v0.2，2026-09-04。依据剧情讨论稿第五节，按 scripts/luo_dialogue.gd 与 scripts/luo_story_scene.gd 同步。

本篇利用 B7 与 ECHO 已有进度，不依赖未实现的 C9/B2。以下“已接入”指代码与素材已接入，不代表运行验证；按用户要求未运行测试、未启动 Godot。

## 设计支柱

- 罗茂从一开始刻意帮助取得信任，不写成后来才变坏。
- 凌霁为成年角色，收礼、赴约、拥抱、轻吻各自独立，当次同意不是后续许可。
- 监视、擅入和隐瞒用日志表现，不展示情色化偷窥镜头。
- 拒绝不阻断调查、主线和正常补给；最后主动结束私人关系，不以退装备证明立场。

### 0：刻意帮助

目的：建立可靠同事表象，供后期重新理解。
输入：基地支线入口，不要求收礼。
演出：罗茂把装备箱推向凌霁，停手等她决定。静态小人之间的箱子色块移动，不是逐帧接箱动画。
对白：“先看参数，别急着答应。我只盼着你平安回来。”
输出：完成表象段。观看不发装备，赠礼仍由原菜单领取。
边界：拒礼照常推进，回看不得刷资源；递箱不代表已经收下。

### 1：秘密与亲密选择

目的：凌霁误以为对方毫无保留，玩家决定是否靠近。
输入：B7 汇报后公共休息区会面；选择“只做同事”“接受这一次拥抱”“接受这一次轻吻与拥抱”。
演出：初始或拒绝显示 trust；明确接受后显示 closeness，凌霁静态小人靠近、停留、分开。拥抱姿态来自插图，轻吻仅以简短非露骨正文确认，没有逐帧接吻动作。
对白：“这只是当下的选择，不是对未来的承诺。”
输出：保存 intimacy 为 refused/embrace/kiss，完成本段；不加装备、好感或顺从奖励。
边界：contact_ended 者保持距离仍可调查；回看不能重新选择。拒绝不显示亲密图，未轻吻不得在后文声称吻过。

### 2：异常记录

目的：让凌霁通过证据发现边界被侵犯。
输入：接受 ECHO 后回基地。
演出：evidence 插图与明暗变化，正文呈现审计摘要；没有独立操作终端动画。
证据：非公开训练排程查询、观察区远程开启、私人舱室无预约进入，备注“送补给”。
输出：备份疑点并完成本段，仍需后续交叉核查。
边界：拒礼、拒绝亲密者都能查证。不是要求玩家前往新地图中的控制台；旧 B7 供货记录不等于这份审计记录。

### 3：恩惠索取

目的：罗茂用下一份情报索取进一步身体亲密，伪装开始破裂。
输入：取得任意两份 ECHO 冰原线索后返回基地。
演出：evidence 插图，凌霁静态小人后退、罗茂变暗；没有独立抬手动画。
对白：“装备和情报都不能替我答应。没有我的同意，不要靠近。”
输出：明确拒绝或结束谈话继续核查，均推进调查，不提供接受强迫交换的选项。
边界：只在曾收赤线/电池时提对应赠礼，不虚构收礼。拒绝不扣资源、不锁主线补给。

### 4：完整真相

目的：将先前所谓及时援助与安排好的监视对应起来。
输入：ECHO 信标 keep 或 shutdown 后回基地。
演出：evidence 插图与正文；图片明暗变化。
证据：先扣下危险路线告警，再私人发送“救命提醒”；排程查询在偶遇之前；门禁、观察区、删改日志相互印证。
输出：完整证据备份，准备交给沈砚。
边界：两种信标结果同样可进入，不发奖励，不当场执行纪律处罚。

### 5：决裂

目的：她可以承认曾信任，却不为罗茂欺骗负责。
输入：ECHO 汇报后回基地对质，选择“提交证据并结束私人关系”。
演出：break 插图包含抬手制止姿态；静态小人后退、罗茂变暗。文字表达结束往来，没有真实转身、走向出口或逐帧抬手动作。
对白：“我以为你是在帮我。原来你只是在计算，要付出多少东西，才能把我变成你的。”
仅 kiss 分支追加：“我相信过你，也吻过你。但那不是你继续进入我生活、碰我的身体的许可。”
输出：stage=6、disposition=submitted、contact_ended=true，私人邀约结束，证据交沈砚等待纪律审查；装备归属不变。
边界：当前只实现提交沈砚，没有多种证据处置、停职判决、监禁或复合。完成后只回看、不重新亲密。
