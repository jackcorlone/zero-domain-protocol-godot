# M2「天穹校验坪」机甲地图设计

## 1. 资产定位

- `*-icon-v1.png` 保留为机体档案、对话和战斗选择卡，不作为地图角色。
- `*-map-sheet-v2.png` 是地图资产：统一透明底、2×2 四方向表，每格 `627×627`，排列为朝下、朝左、朝右、朝上。
- 地图显示高度建议为 `82–104 px`。脚底锚点统一位于单格底部中央，碰撞只覆盖腿部和机体核心，不覆盖肩炮或翼片。
- 首版移动使用方向切换加轻微步态摆动；正式战斗动画后续再拆成移动、攻击、受击和停机帧。

三台机体在玩法中的身份固定：

| 机体 | 地图身份 | 玩法关键词 |
|---|---|---|
| 白曜神盾 | 无人友军试验机 | 调查、启动、护盾支援 |
| 铁垒 | 机械区普通敌机 | 可见巡逻、警戒、过热弱点 |
| 赤线炽天 | 凌霁的主角座驾 | 玩家控制、高机动、超载输出 |

## 2. 地图结构

地图采用近正交俯视的平地 RPG 表现，不使用展柜或大透视机库：

```text
                 北：相控阵校验塔
                    [任务守卫]
                         │
       西：电容站 ── 中央测试坪 ── 东：物流终端
          [可选]        [巡逻区]       [可选]
               \          │          /
                ── 白曜失联位置 ──
                         │
               南：气闸 / 返回基地
```

- 中央保持连续、宽阔的机甲移动与战斗空间。
- 固定设施与场景边界承担碰撞，背景不烘焙角色。
- 普通铁垒在两点间巡逻；玩家可以观察并绕开，不使用随机遇敌。
- 南侧气闸是安全区和返回出口。

## 3. 剧情任务：「空白驾驶员」

推荐前置为《回声之外》完成汇报：

1. 《静默回路》证明有人伪造 LYRA-7 身份。
2. 《回声之外》发现三年前的 LYRA-7 返航记录。
3. 「空白驾驶员」证明旧身份协议可以远程唤醒机体。

沈砚简报：

> M2 测试坪刚刚收到一份驾驶员上线请求。身份是 LYRA-7，时间戳却来自三年前。两台铁垒已经脱离调度，白曜的驾驶舱里没有人，但它报告神经同步完成。

北侧校验塔持续广播：

> 返航校验未完成。请原驾驶员归位。

任务不揭晓克隆、时间穿越或凌霁真实身份，只确认某个旧协议正在把她当成缺失部件。

## 4. 可玩闭环

### 出击与观察

- 凌霁驾驶赤线炽天进入校验坪。
- 玩家可绕开普通铁垒，先调查西侧电容站或东侧物流终端。
- 电容站可将最终铁垒伤害降为 `0.85×`，代价是丢失部分实时记录。
- 物流终端可显示巡逻序列，并让一台普通铁垒暂停巡逻。

### 白曜二选一

调查白曜后发现驾驶舱为空，系统却显示“同步对象：LYRA-7”。启动方式只能选择一次：

- 隔离启动：白曜为玩家抵消最终战斗的第一次重击，只回收静态记录。
- 镜像同步：白曜伪装成第二个 LYRA-7，引出完整握手；最终敌人伤害提高 `15%`，但过热窗口延长一回合。

### 铁垒战斗

- 普通铁垒建议 `160 HP`；北侧任务守卫建议 `240 HP`。
- 前两次行动使用压制射击，第三次行动进入过热，本回合攻击降低或跳过。
- 接近警戒范围后先弹出警告，玩家确认才进入战斗。
- 撤退返回地图并重置敌人 HP；白曜选择和调查结果保留。

### 回收与汇报

- 隔离路线得到“空白驾驶员缓存”，确认协议来自基地建造初期。
- 镜像路线得到完整编号：`LYRA-0 / DRIVER ABSENT`。
- 回收残骸后返回沈砚处结算：`280 CR / 280 EXP`，两条路线基础奖励相同。

## 5. 首版范围

本轮实现：平地地图、赤线地图控制、白曜独立单位、铁垒巡逻与警戒、资料交互、返回基地和可扩展的遭遇入口。

后续实现：两处准备节点、白曜一次性选择、任务守卫战、残骸回收、汇报与存档迁移。

暂不实现：自由换乘、队友 AI、机甲装备树、部位破坏、弹药与热量资源、三台完整逐帧动画、大型随机地图。

## 6. 验收标准

- 玩家一眼能识别连续平地和可走路线。
- 三台机体均为独立地图节点，不烘焙在背景内。
- 赤线随玩家移动并正确切换四方向。
- 铁垒有可观察的巡逻轨迹和警戒反馈，可以绕开。
- 白曜可调查，角色身份与普通敌机明确区分。
- 进入、退出、重复加载地图不会锁死旧任务或存档。
