2026-09-04。代码和图片已保存；遵照要求未跑测试、未启动 Godot，运行效果和导入结果未验收。

## 入口与推进

C → 任务与支线 → 罗老板通讯 → 支线剧情 / 已见记录。新章节须返回指挥中心，已见章节可以回顾。

| 章节 | 前置进度 |
| --- | --- |
| 善意的表象 | 指挥中心 |
| 一次靠近 | 完成 B7《静默回路》并汇报 |
| 门禁留下的影子 | 接受《回声之外》 |
| 恩惠不是筹码 | 收集至少两份 ECHO 线索 |
| 被安排的巧合 | 作出 ECHO 档案处置 |
| 收回信任 | 完成 ECHO 汇报结算 |

按顺序推进，拒绝礼物或亲密不阻断调查。亲密分为拒绝、拥抱、亲吻；图片为克制拥抱，不是独立亲吻逐帧动画。最终主动结束私人关系并向沈砚提交证据。多种公开处置、C9/B2 扩展不在当前实现内。

## 接入范围

- scripts/luo_dialogue.gd：章节、选择、回顾与阶段文案，防止揭露后重新赠礼或邀约。
- scripts/game_state.gd：独立 luo_story 存档段及旧档缺省值，记录阶段、亲密选择、证据处置。
- scripts/exploration.gd：剧情面板、罗茂肖像与头像、任务摘要、长对白滚动。
- scripts/luo_story_scene.gd：静态小角色递箱、靠近后退、拉开距离的 Tween 演出及插图展示。
- assets/npcs/luo-mao-rpg-v1.png：罗茂透明全身立绘，不是行走图集。
- assets/story/luo-trust-v1.png、luo-closeness-v1.png、luo-evidence-v1.png、luo-break-v1.png：四张剧情插图。

美术提示词见 [美术记录](luo-story-art.md)，动作设计见 [演出设计](luo-story-staging.md)。未制作独立可行走室内地图。旧试玩文档中的测试通过仅指历史版本，不适用于本次修改。
