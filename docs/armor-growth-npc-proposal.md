# 《零域协议》破甲、成长与灰色交易设计草案

状态：2026-08-30 已完成首轮可玩代码接入与回归测试；三阶段战损新图、罗茂立绘仍待补。实际已实现范围及暂缓项见 [赤线系统试玩说明](redline-playtest.md)。以下保留原确认方案，不将设计目标一概视为已完成。

确认基线：血量越低，攻击越高；三个阶段包含完整装甲阶段；采用赤线战术服的高输出、低防护与额外MP消耗。罗茂的赠礼、会面和关系选择分别记录；前段建立信任，后段揭露秘密并走向决裂。文中数值作为第一轮实现和试玩基线，后续依据测试调整，不代表已经平衡完成。

## 1. 三阶段装甲表现

凌霁的装甲在危急时主动抛弃受损外板，解除动力限制：更快、更危险，但更脆弱。表现为科幻战损，不以裸露为升级奖励。

| 阶段 | 当前HP比例 | 立绘变化 | 探索移动速度 | 受到的伤害 |
| --- | --- | --- | --- | --- |
| I 完整 | 大于60% | 装甲完整，少量划痕 | 100%（180像素/秒） | 100% |
| II 破损 | 大于30%、不高于60% | 一侧肩甲崩裂，护臂和腿甲缺损，外层布料撕裂、内层战术服保留 | 115%（207像素/秒） | 115% |
| III 解限 | 大于0%、不高于30% | 多块外甲脱落，外骨骼与线路显露，内层不透明战术服保留，青色动力纹发亮 | 130%（234像素/秒） | 135% |

HP为0立即进入失败流程，不触发额外攻击。恰好60%进入II，恰好30%进入III。

第一版不新增独立护甲耐久条。伤害、治疗、升级和失败回收后，统一按当前HP比例同步阶段；治疗物品包含纳米修复剂，以解释外甲恢复。不能出现立绘恢复了、防御却没恢复的状态。

当前战斗采用玩家与敌人轮流行动，没有行动速度系统。本版速度加成仅影响探索移动，不增加战斗行动次数，也不缩短玩家思考时间。若后续希望速度影响先手或行动条，应另行设计，不能只把攻击动画加快当成战斗速度。

### 残血攻击加成

攻击倍率 = 1 + 0.4 ×（1 − 当前HP / 最大HP）。使用出手时的HP；普攻与伤害技能适用，治疗不适用。

- 满血：100%攻击；60%血：116%；30%血：128%；10%血：136%。
- 以基础伤害40为例：60%血约46，30%血约51，10%血约54。
- 防御下降以“受伤倍率”实现，暂不引入当前代码没有的独立DEF数值。
- 现有防御减伤65%继续生效：敌人攻击 × 中继路线倍率 × 破甲受伤倍率 × 防御倍率，最后统一向上取整。
- 现有完美防御反击倍率1.75与残血攻击相乘，最后向下取整；两者共同上限不超过2.45倍基础伤害，不再额外叠加阶段攻击奖励。
- III阶段受到40点基础伤害时变为54；若防御则为19。低血增伤无法抵消所有生存风险，治疗仍有价值。
- 不用减少玩家反应时间、强制连续受击等方式惩罚低血。

### 美术交付约束

三张战斗立绘共用脸、发型、姿势、画布、站位与透明背景，主要改变外甲、布料边缘和灯光；换阶段不能人物跳位。镜头不聚焦胸部或胯部，不添加裸露、色情姿势或血腥伤口。地图小角色只做少量可辨认的肩甲/配色差别，不缩放身体，也不恢复脚底下标。先做大立绘对照，经确认后再扩展各方向走路帧。

## 2. 经验与升级

当前工程只有累计EXP和任务经验奖励，还没有真实等级提升、技能解锁和可重复刷怪循环。保留现有1840 EXP作为LV.3存档基准，不静默清空旧进度。

| 等级 | 累计EXP门槛 | 本级到下级所需EXP |
| --- | --- | --- |
| LV.1 | 0 | 600 |
| LV.2 | 600 | 900 |
| LV.3 | 1500 | 1100 |
| LV.4 | 2600 | 1400 |
| LV.5 | 4000 | 首轮试玩上限 |

界面显示“LV.3 · 本级340/1100”，详情可显示累计1840。当前距离LV.4尚需760 EXP；现有完整记录任务奖励250 EXP保持不变。

从现有LV.3开始，每升一级：最大HP +80、最大MP +30、普攻伤害区间两端 +3、过载突袭伤害区间两端 +6。当前HP/MP同步增加各自上限的增量，不全回满。连续升多级逐级处理，结算界面明确列出成长。

- LV.4解锁“电磁穿刺”：基础90–105伤害，消耗80 MP，单体技能；接受残血与反击加成。
- LV.5解锁“应急屏障”：消耗45 MP，下一次敌方攻击减伤75%，占用一次行动；替代本回合普通防御，不叠乘普通防御、不触发完美防御反击。
- 技能解锁仅执行一次；MP不足不消耗行动。

刷怪区建议增加独立训练回路：巡检机60 EXP、维修蛛90 EXP、精英哨兵180 EXP。主线Sentinel不重复刷新，避免打乱残骸和任务状态；训练敌人回安全区后刷新，每次死亡只结算一次经验，不可通过反复触碰残骸刷奖励。主线哨兵维持原任务统一结算，不新增重复经验。

上述刷怪数量与升级时长需试玩后再调，不要求刷怪才能完成第一段主线。

## 3. 道具与装备

先做小背包：每种消耗品最多持有9个，装备分武器、装甲、模块三个槽。不加入负重或随机词条。

| 道具 | 效果 | 获取方式 |
| --- | --- | --- |
| 医疗凝胶 | 恢复最大HP的25%，随HP同步恢复装甲阶段 | 补给/箱子 |
| 能量电池 | 恢复最大MP的20% | 补给/箱子 |
| 纳米修复包 | 恢复最大HP的45%，较稀有 | 解谜宝箱 |
| 稳压模块（装备） | 最大MP +40，不直接回复当前MP | 中继支线宝箱 |
| 复合护甲（装备） | 所受伤害 ×0.90；探索速度 ×0.95 | 迷宫终点 |

战斗用消耗品占一回合；满值、数量不足或不合法目标时，不扣道具、不消耗回合。战斗中不可换装备，避免反复装备刷血蓝；卸下装备导致超上限时钳制当前值，重新装备不补回。箱子开启状态存档，不能重复领装备。

现有指挥中心补给“凝胶+140 HP / 电池+120 MP”的直接领取流程先保留，避免本轮改坏已确认任务；正式接入背包时再统一旧补给与新道具的说明、效果。

## 4. 新NPC：罗茂，外号“罗老板”

2026-09-04 更新：罗茂立绘、四张剧情插图及六段演出代码已接入，依托 B7/ECHO 进度推进亲密选择、证据揭露与主动决裂。本文旧“仅前段／立绘待补／决裂未实现”描述由 docs/luo-story-integration.md 取代；C9/B2 扩展仍为规划。本轮未运行测试或启动 Godot，历史测试结论不覆盖新增代码。

### 真实动机

成年男性后勤中间商，体型肥胖、圆脸、油亮背头，笑容热络，商用外套不合身，袖口有机油印，手里常拿保温杯。他的问题在于隐瞒动机和操纵人情，而不是体型。

凌霁与罗茂均为成年人。两人开始只有同事关系；罗茂外表和气、乐于帮忙，在凌霁眼中是人畜无害的老好人。他最先因凌霁出众的外形与身材产生欲望，并希望最终占有她、得到她的身体。他前段不会说出这一目的，而是刻意扮演可靠同事。

罗茂动用关系提供真正有用的装备、道具、隐秘路线和经过挑选的“个人秘密”。这些帮助客观上能让凌霁安全完成任务，但他从一开始就把它们当成取得信任、制造情感债和换取亲密关系的投入，不是真正无条件的善意。

凌霁因为相信罗茂的伪装而没有拒绝亲吻与拥抱；她当时的选择不等于同意更进一步。罗茂却将亲密视为投入得到回报，并计划借装备和信息继续索取她的身体。随着任务深入，凌霁发现他秘密查看训练排程与身体状态数据、偷看非公开训练、擅入私人舱室，并扣留信息维持自己的“及时帮助”。她短暂纠结后仍主动结束关系。

### 第一份礼物：“赤线”轻型战术服

黑白轻型战斗服、青色动力线、减少覆盖的外甲和完整不透明内层。它牺牲防护来解除武器输出限制，不靠裸露提供增益。

| 属性 | 试玩提案 |
| --- | --- |
| 装备位置 | 装甲槽，与复合护甲互斥；原装甲保留在背包 |
| 攻击 | 强化攻击的基础伤害 ×3，普攻和伤害技能适用 |
| 防护代价 | 受到伤害 ×2，叠加三阶段破损；III阶段总受伤倍率 ×2.7 |
| 输出代价 | 每次强化攻击额外消耗12 MP；过载突袭总计72 MP |
| 补给 | 使用普通电池，商店和探索均能获得，罗茂不是唯一来源 |
| 卸下 | 战斗外随时换回原装甲，无诅咒锁定或永久属性损失 |

“一刀秒杀”通过演示战兑现：90 HP巡检机，满血最低普攻34 ×3 =102，一击击败。若敌人打出40点基础伤害，穿衣后受伤80，III阶段受伤108。让玩家实际体会强大与脆弱。

残血和反击仍适用；穿赤线时，装备、残血与反击的输出倍率乘积最多为4倍基础伤害，最后取整。未装备时使用前述规则。秒杀定位针对普通敌人，不保证所有精英/Boss都秒杀，主线也不能要求穿它才能通关。

出手前按总MP校验，确认后一次性扣除。MP不够额外12点时明确提示，可取消或选择普通倍率攻击；技能连基础MP都不足时不能施放。不先扣MP再强迫跳过回合。MP耗尽不会解除衣服的防护代价。

服装同样有完整、破损、解限三阶段立绘；共用人物、姿势、画布与HP阈值。穿衣或破甲程度不触发默认亲密事件。

### 第一段：看似真正的帮助

罗茂：“这套不走公库。我给你留着的。先试试，能少挨一场苦战，总比什么都强。”

他赠送赤线并开放安全训练演示，暂不提出私人要求。玩家与凌霁此时只看到善意；编剧层面明确这是罗茂建立信任的第一笔投入。选项：

- 检查属性与来源。
- 接受，但暂不穿。
- 试穿并进入训练演示。
- 拒绝，只问情报。

领取一次；试穿前明示防护与MP代价。拒绝后保留正常主线路径。训练演示结束恢复入场前HP/MP，不给可重复领取的经验或掉落，避免以演示骗取资源或消耗玩家补给。

### 第二段：他带来的便利

首次使用后，他送2块普通电池和维修侧门位置，希望凌霁遇到困难就来找他。

罗茂：“好用吧？别省那点电。电池我这儿还有，你记得回来找我就行。”

选项：接受电池／拒绝后续赠礼／询问他想得到什么／只做正常交易。电池赠礼只领取一次，不循环刷物品；系统不替玩家判定已经依赖或产生好感。

### 第三段：从同事到短暂亲密

罗茂在任务结束后邀请凌霁吃饭，表面上不把新装备当作条件。他逐渐告诉她非公开运输线、旧管理员和试制装备担保的部分秘密，让她误以为自己得到了特别信任。凌霁可拒绝、只在公共场所见面，或进一步了解他。

若玩家选择靠近，两人在一次任务后的安静场景中亲吻并拥抱。凌霁相信罗茂一直真心保护她，明确接受这一次亲密，而非仅以沉默表示；罗茂则把这视为继续索取身体关系的开端。场景到拥抱结束，不写露骨内容，也不把过去的接受解释成对后续接触的同意。

### 第四段：秘密暴露与最终决裂

地区任务深入后，凌霁发现罗茂一直利用后勤权限读取她的训练排程与身体状态数据；他曾躲在观察区偷看非公开训练，也以检查装备为借口未经允许进入她的私人舱室。他还扣下部分任务信息，使自己能在关键时刻出现并继续扮演唯一可靠的帮助者。

当罗茂开始用装备、情报和过去的亲密暗示凌霁应该允许更进一步的身体关系时，门禁日志、权限查询、被移动的物品和监控访问记录拼出了完整事实。他的善意是一场长期表演，而不是后来才变坏。

凌霁短暂怀疑自己是否因为没有更早拒绝才导致越界，最终确认欺骗与侵犯边界是罗茂的责任。她主动结束关系；亲吻和拥抱不构成永久承诺。玩家仍决定是否公开全部证据、是否保留合法获得的装备，以及是否关闭所有任务通讯。

偷窥、擅入与数据滥用只通过证据和后果呈现，不用睡衣、身体特写或情色镜头把骚扰包装成福利。

拒绝的代价仅限于失去后续专属赠礼和优惠；不撤回经验、不扣未知资产、不强制失去衣物、不锁主线。自愿退还前提示确认，退还后关闭赠礼事件，不能重复领取套利。

### 情报支线与独立出路

- 正门：原有路线，默认装备可通关。
- 维修侧门：额外巡检机战斗、修复包宝箱和非公库供货记录；门口日志预告危险，可退出。记录在前段只揭示罗茂动用了旧关系，不直接证明其黑暗面。
- 不收礼仍可自行探索发现侧门，或花80 CR买一次位置情报；余额不足不扣款，已解锁不重复收费。
- 普通商店提供电池；任务和宝箱提供不依赖罗茂的装备成长路线。

记录首次会面、服装领取/退还、一次性补给、侧门发现、邀约回应、揭穿和停止往来。装备状态与对话状态独立，不引入“身体欠债值”、强制好感或隐藏服从数值。

## 5. 接入顺序与验收

1. HP阶段与数值 → 测试60%、30%、0边界、治疗回升、反击和防御结算；探索速度不得影响战斗回合数。
2. 三阶段美术 → 同画布三图，透明背景，换图无跳位，伤害与回蓝后的状态同步。
3. EXP和技能 → 从1840加760应恰好到LV.4；大量经验可连升、不重复解锁；旧任务不重复给经验。
4. 背包和箱子 → 使用数量减少一次，满血不浪费凝胶，退出重进不重领宝箱；装备切换不能刷HP/MP。
5. 赤线装备 → 满血最低普攻能击败90 HP演示敌人；受伤/MP代价正确，叠乘限幅4倍；不足总MP可取消或明确选择普通倍率，换装不丢原装甲；演示恢复入场HP/MP且不刷奖励。
6. 罗茂交互 → 收礼、穿衣、接受邀约分别记录；赠礼不重复、花费不透支、每次邀约可拒绝、拒绝不阻断主线；退还后不能重复领装备。

用户已确认本版方案，包括三阶段定义和赤线倍率、MP代价的试玩提案。当前数值、赤线/道具和罗茂首轮支线已接入，经验与技能已测试。生成美术时图片服务达到额度上限，故战损新图尚未完成；不将完整造型回退图当作战损立绘验收。
