# 《潮汐盲区》NPC与怪物阵容

版本：v0.1  
设计基准：凌霁约1000 HP；普通攻击34–42；技能伤害72–125。以下数值均为首轮 `[PLACEHOLDER]`，需要实机测试。

## H1星港候机环NPC

### 贺岑｜男性，36岁

- 身份：H1航路调度员、退役海洋救援艇驾驶员。
- 外形：高瘦成年男性；短黑发带一道银色发束；旧橙色飞行夹克、深蓝防水工装裤、机械式左腕导航器；服装有长期盐蚀痕迹，常拿折叠星图。
- 性格：务实谨慎，不认同没有返航方案的“英雄式冒险”。曾在涅柔斯-4失去救援队。
- 功能：提供三段浪向提示；让玩家在“风暴绝缘模块”和“额外MP电池”中选择一个；若玩家在卧室分析过风暴频谱，则开放安全但较慢的隐藏航路。
- 支线：找回失踪救援艇黑匣子，解锁甲板安全索强化。
- 台词：“返航燃料不是胆怯，是让下一次任务仍有人能出发。”

### 祁雾｜女性，31岁

- 身份：异星生态检疫官、零域共生体研究员。
- 外形：短银灰发；青绿色检疫半披风覆盖白灰工作服；腰间悬浮样本盒和小型扫描无人机；干净理性的冷色轮廓与星港橙色工业环境形成对比。
- 性格：冷静、尊重未知生命，不把潮根生物简单归类为怪物。
- 功能：制作“抗黏附喷剂”，立即解除束缚并在两回合内免疫再次束缚；分析组织与神经晶片；判断自然攻击和人工控制。
- 反馈：玩家若主动消灭大量非敌对生态体，她会取消额外样本奖励，但不会锁死主线。
- 支线：完整带回根冠神经晶片，获得“生态干扰器”蓝图，使潮根敌人首回合不主动攻击。
- 台词：“会攻击你，不代表它想杀你；也可能只是有人替它定义了疼痛。”

两名NPC提供不同但都合理的价值观：贺岑强调存活和撤离，祁雾强调理解生态和减少破坏。

## 潮根滩涂怪物

### 普通怪：潮须潜根

- 轮廓：潜伏泥层的低矮深蓝装甲根节，末端分成三条感震触腕，表面覆盖贝壳状甲片。
- 定位：近战控制、地形驱赶。
- HP / 伤害 / EXP：`160 / 36–44 / 120`。
- 技能：`泥下横扫`造成伤害并推离安全格；`根须锚定`蓄力后束缚，使探索速度下降且战斗中无法闪避。
- 弱点：切割伤害×1.35；攻击前以投石制造假震动，可令首回合攻击落空。
- 掉落：潮根纤维；低概率抗黏附腺体。
- 地图联动：跑动扩大警戒圈；缓慢移动、投石和共振板会改变钻出位置。

### 普通怪：孢囊漂体

- 轮廓：扁圆浮囊，内部有青白色孢子光点，下方只有短须根，远程轮廓明显。
- 定位：减速、治疗辅助。
- HP / 伤害 / EXP：`125 / 28–36 / 135`。
- 技能：`黏雾喷散`使下一次束缚更难挣脱；`共生脉冲`为另一敌人恢复45 HP，每场最多两次。
- 弱点：穿刺伤害×1.5；遭闪电或导电地面命中会失去一回合。
- 掉落：发光孢囊、MP恢复材料。
- 地图联动：关闭附近共振柱后，它会下降并暂时失去治疗能力。

### 精英怪：根冠母体

- 轮廓：固定在巢穴中的巨型珊瑚树冠生物；厚重根甲包围人工青蓝神经晶片；护卫触腕呈根系结构。
- 定位：机关型精英、召唤和区域预警。
- HP / 伤害 / EXP：`430 / 48–64 / 390`。
- 技能：`根冠闭合`减伤40%；`三向震击`预告三个波纹区后攻击；`强制共振`每三回合召出临时触根，场上最多两条。
- 弱点：关闭三枚共振柱后核心暴露两回合，受到伤害×1.6。
- 掉落：人工神经晶片、根冠甲片、生态干扰器任务材料。
- 地图联动：投石可欺骗一道震击；提前切断根节可开捷径，但以高警戒状态开战。

## 沉眠者回廊怪物

### 普通怪：潮印侍从

- 轮廓：披着陶瓷甲片的四足遗迹构造体，头部是一圈没有中心的发光刻度。
- 定位：位置交换、惩罚重复行动。
- HP / 伤害 / EXP：`180 / 38–46 / 155`。
- 技能：`错位步`交换实体与投影位置；`门框冲撞`对连续使用同一行动的玩家追加伤害。
- 弱点：轮换攻击、防御、技能会使刻度过载，受到伤害×1.4。
- 掉落：潮印陶片、门框校准齿。
- 地图联动：正确旋转门框后无法使用错位步；错误门框会生成一次性镜像假体。

### 普通怪：无面观测体

- 轮廓：悬浮黑色多面体，水滴形透镜环绕，没有脸和生物触腕。
- 定位：记录并克制重复技能、削减MP。
- HP / 伤害 / EXP：`145 / 32–42 / 170`。
- 技能：`动作复写`记录上回合技能，再次使用同一技能时获得反射盾；`认知抽样`削减18 MP，防御可完全阻止。
- 弱点：零域干扰会清除记录并眩晕一回合；从透镜未注视方向攻击，伤害×1.5。
- 掉落：观测透镜、认知滤片、少量MP恢复剂。
- 地图联动：关闭低语后背击窗口延长；保留低语可借透镜照出隐藏门。

### 精英怪：逆谱合唱体

- 轮廓：多个悬浮陶瓷音叉、鱼骨状晶格和倒流水环组成的集合生命，中心为开裂认知核心。
- 定位：声纹辨识、失真度压力。
- HP / 伤害 / EXP：`400 / 44–60 / 420`。
- 技能：`三声伪门`用三种声纹给出真假攻击预告；`逆序回响`把最近三次行动倒序表现为干扰；`失真涨潮`每回合增加10失真度。
- 弱点：连续辨认两次正确声纹后，水环停止两回合，受到伤害×1.7。
- 掉落：逆谱核心、失真抑制器蓝图、遗迹声纹记录。
- 地图联动：关闭低语降低失真但减少提示；保留低语更易识别真声纹，但持续承受MP压力。

## 裂潮海怪物

### 普通怪：裂鳍猎兽

- 轮廓：鲨鳍与甲壳蜥蜴结合的低伏海兽，六条短肢吸附甲板，背鳍像破裂船帆。
- 定位：巨浪后突进、群体增伤。
- HP / 伤害 / EXP：`170 / 40–48 / 150`。
- 技能：`逆浪扑击`在巨浪后攻击，对未进掩体目标伤害提高50%；`裂鳍围猎`在场上有同类时攻击提高20%，最多一层。
- 弱点：火、电伤害×1.3；被安全索拉回时撞上栏杆并眩晕。
- 掉落：裂鳍甲片、防滑胶质。
- 地图联动：巨浪也会冲走未固定的猎兽，玩家需要在输出和锚机操作之间选择。

### 普通怪：引雷水母

- 轮廓：暴雨中漂浮的深蓝伞状生物，体内有金色电弧，仅带短小导电丝。
- 定位：导电标记、MP压制。
- HP / 伤害 / EXP：`135 / 30–40 / 165`。
- 技能：`导电标记`令下次闪电优先命中目标；`静电虹吸`削减20 MP并强化下一击。
- 弱点：绝缘模块可抵消一次标记；在闪电蓄积时击破外囊会触发反噬并波及其他敌人。
- 掉落：蓄电胶囊、MP电芯、绝缘膜。
- 地图联动：可把标记引向锚链、敌人或可破坏货箱。

### 精英怪：深潮脊兽

- 轮廓：装甲海脊如移动礁石和破损舰壳，发光鳃线显示攻击方向；战斗中只让部分身体进入画面以强调体量。
- 定位：甲板区域Boss、锚机破防。
- HP / 伤害 / EXP：`460 / 52–72 / 450`。
- 技能：`破浪横脊`预警后横扫半块甲板；`拖锚下潜`锁定锚链，不干预会摧毁一个安全区；低于40% HP后使用`风暴呼吸`缩短浪潮周期并持续暴露鳃线。
- 弱点：锚机限制一回合；鳃线受到伤害×1.6；被引雷水母标记后遭闪电命中会打断蓄力。
- 掉落：深潮脊骨、风暴鳃晶、甲板武器模组蓝图。
- 地图联动：攻击、锚机、救援科研员和保护样本不能同时完成。

## 平衡与失败边界

- 普通怪：单只应在3–5次普通攻击或2–3次技能内击败；单战消耗玩家约10%–22% HP。
- 精英怪：裸打约9–12次普通攻击；利用地图弱点后缩短为5–7个有效输出回合。
- 三只精英必须有清晰攻击预告，首次失败后玩家应能准确说出失败原因。
- 普通怪掉消耗品与材料，精英掉任务材料或蓝图，不直接泛滥完整装备。
- 零MP、零消耗品时仍能依靠普通攻击、防御回复和地图机关通关。
- 召唤物有数量上限；控制效果不能连续无限叠加。
- 触腕束缚只造成战术限制和耐力损失；不包含情色、羞辱或永久控制表现。
- 失真度满值只触发镜像战并返回安全锚点，不删除道具或存档。
- 落水由安全索救回，损失行动窗口与少量HP，不立即死亡。

## Godot接入设计

当前 `battle_screen.gd` 依靠 `encounter_id` 分支硬编码敌人贴图、HP、伤害倍率、标题和提示。为11个新角色直接继续添加长分支会迅速失控；本章最低限度使用数据表承载静态配置，特殊机制仍保留小型分支。

建议的9个encounter id：

```text
voyage_tide_root
voyage_spore_drifter
voyage_root_matriarch
voyage_tide_acolyte
voyage_faceless_observer
voyage_mnemonic_choir
voyage_rift_fin
voyage_storm_medusa
voyage_ridgebeast
```

建议新增静态字段：

```gdscript
const ENCOUNTERS := {
    "voyage_tide_root": {
        "name": "潮须潜根",
        "max_health": 160,
        "damage_min": 36,
        "damage_max": 44,
        "exp": 120,
        "rank": "common",
        "environment": "tentacle_field",
        "status_profile": "bind",
        "drop_table": "tide_root_common",
    },
}
```

NPC不放进战斗配置：

- `starport_hangcen`：航路、模块选择、黑匣子支线。
- `starport_qiwu`：检疫、抗黏附喷剂、生态干扰器支线。

最小修改点：

- `scripts/game_state.gd`：新增独立 `voyage` 状态、NPC对话状态、怪物首杀和精英击败状态，并加入存档迁移。
- `scripts/expedition.gd`：星港NPC互动点、三张地图敌群触发、胜负回调和地图机关状态。
- `scripts/battle_screen.gd`：从配置读取静态战斗数据；实现束缚、失真、导电标记三个可复用状态；精英只添加各自的阶段逻辑。
- `assets/npcs/`：最终拆分后的两张透明NPC立绘。
- `assets/enemies/`：最终拆分后的九张透明怪物立绘。

至少新增测试：

- 9个encounter id均有有效贴图、名称、HP和掉落表。
- 普通怪胜利正确给予EXP且不能重复结算。
- 三只精英胜利分别推进 `tentacle_core_destroyed`、遗迹选择前置和 `storm_boss_defeated`。
- 束缚存在免疫回合；召唤物数量受限；零MP仍可通关。
- 失真满值不覆盖安全存档；落水回收不清除已取得任务物品。
- NPC模块二选一不可重复领取；旧存档载入后使用默认值。
