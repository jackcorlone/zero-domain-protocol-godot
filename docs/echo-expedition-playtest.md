# 回声之外 · 外勤试玩说明

2026-08-30，Godot 首版已接入。保留科幻世界观、2D 小角色探索和独立回合制战斗，没有改成 3D 游戏。

## 怎么进入

1. 在 Godot 打开本工程，停止旧运行窗口后按“运行项目”（F5），选择「继续存档」。不要为了进入新区域而重新开档。
2. 完成原有「静默回路」并在指挥中心与沈砚交谈，接受「回声之外」。旧主线的两种记录结果都可以接任务。
3. 东侧电梯按 E，选择「H1 · 飞船舱」。原 B7 入口保留。
4. 在机库走到游隼舷梯按 E，确认出航。航行过场可按 Enter、Esc 或跳过按钮结束。
5. 着陆后沿道路探索。靠近路口按 E 换地图；WASD/方向键移动，C 看角色和装备，M 看导航，Esc 关闭界面或返回菜单。

机库可与工程员岑遥对话或购买标准补给。返航不收费，但不自动补满 HP/MP。

## 这次能玩什么

区域连接：基地电梯 → H1 机库 → 飞船 → 着陆点 → 三条相连支路 → 观测站 → 档案室。飞船可随时原路返航。

| 地点 | 调查与选择 | 世界变化 |
| --- | --- | --- |
| 断讯高地 | 读取天线记录；可选修复灯标 | 获得一条线索；修复后导航显示道路，同时出现可选巡逻敌人 |
| 坠毁货船 | 读取运输清单；可选解锁救援舱 | 获得一条线索；获救者移至着陆点，救援奖励只发一次 |
| 裂隙栈道 | 查看工程控制器；可选修桥、找测绘箱 | 获得一条线索；桥面真正出现、障碍移除，开放高架捷径 |
| 废弃观测站 | 正门战斗 / 维护口解谜 / 身份核验 | 三种方式均可取得进入档案室的权限 |
| 档案室 | 核验至少两条线索，读取返航记录 | 明确确认后选择保留或关闭信标，然后回基地交付 |

三条调查支路可任意顺序访问，不要求清怪；任意两条线索足以完成任务。身份核验路线另外需要货船清单；不持有清单仍可用维护口路线。第三条线索是可选探索奖励。

关闭信标会解除该区域守卫/巡逻显示；保留信标则保留警戒。两种选择基础奖励相同，首次交付沈砚获得 300 CR / 300 EXP。结算后仍可重返区域。

## 可选奖励

- 第三条唯一线索：50 EXP。
- 救援：60 CR / 80 EXP，一次性。
- 修桥：60 EXP，一次性。
- 测绘箱：导航模组，显示路线提示；当前是探索工具，不占战斗装备槽、不增加攻击或防御。
- 灯标巡逻敌人：30 CR / 60 EXP，每次重新从机库出航可刷新；可以完全绕开。
- 正门守卫是入口选择，不另外发放主任务奖励。

## 无战斗试玩路线（含解谜答案）

着陆点 → 高地天线下载记录 → 货船运输清单 → 观测站维护口（旁路 → 验压 → 开舱）→ 进入档案室 → 读取主控台并确认信标处置 → 原路回着陆点登舰 → H1 左侧电梯回基地 → 沈砚提交记录。

这条路线已测试：空背包、零 MP 也能完成。不必开灯标，不必救援或修桥。

可选谜题答案：灯标「短 → 长 → 短」；救援「泄压 → 断电 → 开锁」；桥梁「接地 → 供电 → 搭桥」；测绘箱「山脊 → 河谷 → 营地」。错误输入不扣道具，不永久锁死。

## 存档与当前边界

- 使用原存档文件，读取旧版 v1 后首次成功写入 v2 前，会保留一份 `.v1-backup`；旧角色、装备、背包、罗老板选择与主线记录继续保留。
- 保存外勤所在区域、线索、救援、桥梁、宝箱、信标和奖励状态。继续游戏恢复到对应区域的安全出生点，不是精确坐标。
- 这是一段有限区域外勤，不是无缝开放世界；各地图有实际碰撞和路口，航行是约 3.5 秒可跳过的 2D 过场，不含手动驾驶。
- M 当前为可滚动的区域/道路列表，尚非绘制式小地图。修桥用动态桥面表现。
- 新增七张区域背景、一张航行插画和工程员小角色；敌人和获救者暂复用现有素材。战斗背景使用所在地区图片，尚未另绘横版战斗专用背景。
- 原三阶段战损新立绘等美术欠项不在本轮完成范围。设计稿的 20–30 分钟是目标，不是已测得的游玩时长。
