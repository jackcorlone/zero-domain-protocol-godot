# 支线：《绝世宝剑·赤晶洞窟》

版本：v0.1  
定位：15–25 分钟支线；探索、连续单敌战斗、一次不可逆抉择。  
内容边界：凌霁为成年人；强迫劳役与被俘只作为压迫性失败结局，不包含色情、羞辱、暴露或性暴力。

## 剧情概要

基地在哥布林洞穴深处侦测到一件能够切断异常能量的古代兵器——绝世宝剑“界断”。凌霁进入菌灯洞窟，希望以药品、合金和能源电池交换宝剑。

哥布林祭祀同意交易，条件却是凌霁永久留在洞穴、交出武器和行动自由，负责开采赤晶与维护遗迹。玩家可以接受并进入强迫劳役 BE；也可以拒绝，击败十名守门者后挑战祭祀，最终取得宝剑。

```text
基地接取任务
  ↓
探索菌灯洞窟
  ↓
交易石台：祭祀提出强迫劳动契约
  ├─ 接受 → BE-01「没有归期的契约」
  ├─ 追问信息 → 得知遗迹与十枚骨印，再次选择
  └─ 拒绝 → 击败10名不同的巨型哥布林
                 ↓
             提交10枚守门骨印
                 ↓
              挑战祭祀
             ├─ 战败 → BE-02「赤晶囚笼」
             └─ 胜利 → 宝剑认主，获得“界断”
```

## 第一幕：进入菌灯洞窟

任务目标：`寻找通往洞穴深处的道路`

凌霁：

> “信号就在地下。宝剑如果真能切断零域污染，这次最好不要靠抢。”

可探索内容：

- 废弃采矿车：一次性恢复道具。
- 哥布林壁画：说明宝剑来自遗迹，并非哥布林铸造。
- 被锁补给箱：消耗开锁工具，提前获得抗性道具。
- 三条路径：安全长路、陷阱捷径、隐藏补给路。

## 第二幕：交易石台

凌霁：

> “我不是来占领洞穴的。我带来了药品、合金和能源电池，用它们交换祭坛上的剑。”

哥布林祭祀：

> “宝剑不换这些。你留下，武器留下，名字也留在石板上。替部族开采赤晶，直到洞穴不再需要你。”

凌霁：

> “永久留下，还要交出行动权？这不是交易，是囚禁。”

玩家选择：

1. `我接受契约。`
2. `说清楚，你们为什么需要我？`
3. `拒绝。让开。`

追问会得知只有外来者能够安全接触遗迹设备，祭坛封印需要十枚守门骨印才能解除。追问不会替玩家作决定，之后仍需接受或拒绝。

## 路线A：委屈求全

凌霁放下武器。洞穴出口闭合，工作牌与采矿工具被放到她面前。远景中，她仍穿着完整装备，在赤晶矿区搬运矿石。

旁白：

> “任务没有失败，宝剑也没有离开祭坛。只是从这一天起，基地再也没有收到她的归航信号。”

结局：**BE-01「没有归期的契约」**

- 返回结局菜单或契约选择前的安全存档。
- 不覆盖主线自动存档。
- 只解锁“强迫劳动契约”情报，不给予数值奖励。

## 路线B：拒绝并战斗

凌霁：

> “我愿意交易，但不会拿自由做价码。既然你们只认力量——那就让祭坛自己决定持剑者。”

祭祀：

> “击倒十名岩背守卫，你才有资格站到我面前。”

任务更新：`击败巨型哥布林 0/10`

### 十名守门者

为适配现有单敌回合制，每场只出现一名巨型哥布林：

- 第1–3名：岩背守卫，教学蓄力攻击与防御。
- 第4–7名：分别加入湿滑地面、落石警告、赤晶增幅等环境词缀。
- 第8–10名：精英变体，轮流使用盾击、狂怒与破甲重锤。

每名不同守卫只掉落一枚“守门骨印”；重复刷新的敌人不累计任务数量。每击败三名可返回菌灯营地恢复，选择连续推进可获得 `[PLACEHOLDER +10%]` 掉落加成。

### 探索与备战

- 塌方岔路：寻找炸药，或诱导巨型哥布林砸开岩壁。
- 菌灯温泉：一次性完全恢复 HP/MP。
- 俘虏工匠：获救后削弱祭祀护盾，并提供宝剑来历。
- 赤晶共鸣柱：正确激活三根晶柱，使 Boss 最大 MP 降低 `[PLACEHOLDER 20%]`。
- 隐蔽武器架：获得“钝击抵抗模块”。
- 遗迹记录：集齐三份后解锁宝剑附加能力。

## Boss：幽孢祷者

触发条件：向赤晶祭坛提交十枚守门骨印。

祭祀：

> “十名岩背都没能拦住你。很好——现在证明你不会被剑里的力量吞掉。”

凌霁：

> “我来这里不是为了证明服从。我只需要带它回去，救下还活着的人。”

阶段一（HP 100%–51%）：

- 赤晶飞弹：普通法术伤害。
- 汲取咒：造成少量伤害并削减玩家 MP。
- 祭祀屏障：使用破防技能或连续攻击打断。

阶段二（HP 50%以下）：

- 深窟仪式：蓄力一回合，下一回合造成高额伤害。
- 玩家可以爆发打断、使用防御道具，或攻击仪式核心。
- 若完成赤晶共鸣柱，蓄力时间延长一回合。

## 战败结局

祭祀战败后，凌霁被解除武装，关在赤晶照亮的石牢内。装备保持完整，不出现羞辱、暴露或身体侵犯；石牢外可以看见重新供奉在祭坛上的宝剑。

旁白：

> “她醒来时，出口已经封死。宝剑仍在原处，而基地的救援信号无法穿透洞窟。”

结局：**BE-02「赤晶囚笼」**

普通守卫战失败可直接读取战前检查点；祭祀战失败时，玩家可选择观看 BE 或立即重试。

## 胜利与奖励

祭祀倒下后，凌霁没有处决它。她解除祭坛封印，宝剑响应 LYRA-7 的神经签名，刃上的赤光转为青白色。

### 绝世宝剑“界断”

- 类型：单手长剑。
- 基础攻击：`[PLACEHOLDER 72]`。
- 断域：对异常、护盾和施法单位造成 `[PLACEHOLDER +50%]` 伤害。
- 寒锋：对冰属性怪物造成双倍伤害。
- 界线斩：消耗 `[PLACEHOLDER 30 MP]`，造成 `[PLACEHOLDER 220%攻击]` 伤害并优先打断蓄力。
- 过载：连续使用界线斩后进入一回合冷却，防止无限打断。

其他奖励：

- 约足以提升一级的经验值 `[PLACEHOLDER]`。
- 哥布林赤晶 ×6 `[PLACEHOLDER]`。
- 解救工匠：基地锻造折扣。
- 集齐遗迹记录：开启后续任务“失落的铸剑者”。

## Godot 最小接入方案

现有工程已经具备对话选项、剧情图片、单敌回合制、`encounter_id`、胜负回调、C键任务页和存档能力。十名守卫应实现为十次独立遭遇；若改为十敌同屏，需要额外开发敌方队列、目标选择和多血条系统，不属于最小接入范围。

建议状态：

```gdscript
const GOBLIN_ARC_DEFAULTS := {
    "accepted": false,
    "negotiation_seen": false,
    "route": "", # "" / "fight"
    "giants_defeated": 0, # 0..10
    "shaman_defeated": false,
    "sword_claimed": false,
}
var goblin_arc: Dictionary = GOBLIN_ARC_DEFAULTS.duplicate(true)
```

接入顺序：

1. `game_state.gd`：增加哥布林支线状态和武器持有/装备字段，存档升级并兼容旧档。
2. `expedition_maps.gd`：注册 `goblin_cave`、`goblin_depths`、出生点和碰撞区域。
3. `expedition.gd`：增加谈判点、十个唯一守卫遭遇、祭坛门槛和宝剑台。
4. `battle_screen.gd`：增加 `goblin_giant` 与 `goblin_shaman`，并为祭祀增加MP侵蚀行为。
5. C键任务页显示 `巨型哥布林 X/10`、祭祀状态与宝剑状态。
6. 哥布林相关失败先显示非羞辱BE，再读取最近洞穴安全存档。

必须验证：撤退和失败不增加击杀数；第9只不能进入Boss战；第10只立即解锁；祭祀和宝剑奖励不可重复；BE不覆盖安全存档；旧存档能补齐默认状态。
