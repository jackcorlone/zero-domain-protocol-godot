## 新入口

按 C 打开大立绘，右侧分成三个页签：

- 角色与装备：角色状态、护甲切换、背包道具、MP 模块。
- 任务与支线：主线目标、外勤状态、罗老板选择与通讯、B7 维护支路目标、基地训练与补给。右上角不再常驻三个服务按钮。
- 保存与设置：立即保存、主音量、静音、全屏、保存并返回主菜单。

页内内容较长时可滚动。C 或 Esc 关闭菜单并恢复移动。自动保存保留；手动保存覆盖同一存档，恢复时仍回到所在区域安全点。写入失败会提示且不执行“保存并返回”。

设置写入独立 `user://settings.cfg`，主菜单和游戏内共用。音量与静音实际连接主音频总线；本轮不新增音乐素材。战斗中不能打开探索菜单或手动保存。

训练仍要求人在指挥中心；补给购买要求在指挥中心或H1机库。菜单不是远程传送，也不会在野外触发错误的基地训练场景。罗老板通讯可在外勤打开。

## 罗老板后续空间

- 现有赠礼、接受/拒绝、退还、供货记录与质问都保留。
- `contact_ended` 继续读取旧存档，含义限定为暂停私人往来；不把它当成任务交易的封锁条件。旧版已经停止往来的玩家也能继续询问任务情报。
- 退还赤线仍会失去这件服装且不能反复索取，不偷偷撤销用户选择；但不阻止后续关键道具剧情。
- 质问只标记“已经核实/持有证据”，不终结支线、不结算结局。
- 同意了解会面安排不再直接跳到“你已站在店门口”。只留下未展开的会面和物品线索，可改变答复。
- 罗老板手中的东西暂不命名、不赋予属性、不确定交易条件，也不加入背包；相关对话明确标注后续尚未开放。
- 本轮尚未实现亲吻、拥抱、秘密暴露和决裂场景，也没有隐藏的不可逆触发器。后续关键道具仍应允许独立任务或正常交易路线；私人关系最终按新剧情走向结束。
