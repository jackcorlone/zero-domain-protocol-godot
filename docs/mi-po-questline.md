# 弥珀角色支线：《为活者调弦》

> 版本：v1.0（2026-10-11）  
> 状态：已接入游戏并通过自动化测试  
> 依赖：《灰烬遗言》余烬村、《镜后回声》闻缄战、《归潮》岳沉戈终战  
> 首版时长：15–25分钟

## 1. 设计目标

玩家不是靠选择讨好的台词取得弥珀信任，而是用可验证的行动证明自己能分辨真实、尊重死者、优先保护活人。弥珀也不是等待被救的奖励角色；她从“守住已消失的文明”转向“让记忆与活着的人继续前进”。

完整闭环：

~~~text
稳定余烬村避难所
→ 在地下共振档案库初遇弥珀（信赖0）
→ 完成档案时钟、真实脉搏、姓名归还三项非战斗校验（信赖30）
→ 修复三处生活档案共振节点
→ 选择共同保管并优先撤离民用档案（最高信赖80）
→ 获得闻缄战与岳沉戈战的有限支援
→ 真结局中弥珀加入幸存者监督席
~~~

设计边界：

- 支线可改变后续体验，但不能卡主线。
- 弥珀提供信息和一次容错，不自动解谜或击杀Boss。
- 信赖只有0、30、80三个阶段；重复对话不增加信赖。
- 信赖80代表共同承担，不强制定义恋爱关系。

## 2. M0：余烬下的第九个信号

**触发：** ruins.accepted 为真、ruins.shelter_secured 为真，玩家进入 ruin_vault。复用现有相位库地图，并使用 aspera-resonance-archive-map-v1.png 作为共振档案区域背景。

相位库旁出现“独立共振舱”。象牙白舱体与主库断开，仅由三段破损机械圆环维持。生命信号和档案时间戳不一致，先让玩家怀疑这是幸存者还是闻缄留下的诱饵。

首次对话：

> 弥珀：“停在线外，蓝星执行者。你的脉搏是真的，你携带的坐标却有一半在说谎。”  
> 凌霁：“所以别相信我的制服。告诉我怎么证明。”  
> 弥珀：“三次校验。时间、生命，以及你怎样对待不能再回答的人。”

**状态输出：** mi_po.met 变为真，trust 保持0。  
**任务提示：** “为活者调弦：完成弥珀的三项真实性校验。”

## 3. M1：三项非战斗校验

三项可以任意顺序完成。错误只重置当前短题，不扣HP/MP，不销毁线索；已完成项目立即存档。

### 校验A：恢复档案时钟

**交互点：** 共振档案库“档案时钟”。  
**玩家输入：** 根据天文日出、避难所断电和主炮影像三个固定事件，依次选择：

~~~text
天文锚定 → 断电对时 → 剥离伪时戳
~~~

**成功：** mi_po.clock_restored 变为真。  
**失败：** 当前序列复位。  
**反馈：** “你排列的是终端声称的时间，不是天体留下的时间。”

**目的：** 教会玩家“系统时间不等于真实事件时间”，为闻缄的伪指令铺垫。

### 校验B：区分真实脉搏与镜像信号

**交互点：** 共振档案库“生命频谱台”。  
**玩家输入：** 三组信号同时显示波形、编号和反应延迟；选出唯一具备“不完全周期、呼吸漂移、现场延迟”的信号。  
**成功：** mi_po.pulse_verified 变为真。  
**失败：** 保留三组信号并标出一条矛盾，不随机换题。  
**反馈：** “镜像完美得像一段录音。真正活着的东西会犹豫。”

**无障碍：** 不只依赖红绿颜色，同时使用形状、编号和“周期/漂移”文字。

### 校验C：把名字送回地表

**前置：** 已初遇弥珀。  
**玩家流程：**

1. 从共振舱取得七枚遇难者姓名片。
2. 返回 ruined_village 的纪念塔。
3. 将姓名片逐一插入纪念墙。
4. 回到共振档案库向弥珀复命。

**成功：** mi_po.memorial_returned 变为真。  
**重复交互：** 纪念墙可重看七人的姓名与生前职责，但不重复奖励。

弥珀：

> “你没有问他们能换多少装备。凌霁，这是我第一次直接叫你的名字。”

### 三项结算

当 clock_restored、pulse_verified、memorial_returned 都为真：

- mi_po.trust 从0变为30。
- mi_po.joined 变为真。
- 解锁被动“相位辨识”和隐藏共振节点提示。
- 结算一次性奖励：[PLACEHOLDER] 180 EXP。

奖励低于余烬村主线的500 EXP，避免可选人物线变成必须刷取的经验来源。

## 4. M2：把名字带出去

**触发：** trust 至少30且 ruins.secret_recovered 为真。

弥珀说明，相位库中还有一组“生活档案”被三处错位节点隔离。档案不含武器，只有学校名册、农作谱系、歌曲和民用航路。

### 解谜支援节点：三点共振修复

**交互点：**

1. 余烬村钻击坑；
2. 倒塌观测台；
3. 地下共振档案库。

每处从“正相、反相、静默”选择一个状态，目标组合为：

~~~text
钻击坑：反相
观测台：静默
档案库：正相
~~~

弥珀会解释频谱，但不会替玩家选择。错误组合只复位本轮设置；中途返航保留已经确认的节点，不设置倒计时。

三处正确后，玩家分两步决定：

1. **保管方式**
   - 阿斯佩拉幸存者与蓝星共同保管：弥珀持主密钥，蓝星持验证副本。
   - SITE OMEGA单方保管：获得完整技术副本，但弥珀保持职业合作距离。
2. **运输优先级**
   - 优先撤离生活档案和幸存者：放弃同舱稀有军用调谐模块。
   - 优先回收军用模块：民用档案等待下一班运输，不会被销毁。

只有“共同保管＋优先生活档案”令 trust 从30变为80。其他组合仍完成任务，信赖保持30，不使用负好感羞辱玩家。

**完成奖励：**

- 基础：[PLACEHOLDER] 220 EXP、160 CR。
- 信赖80：解锁“反相屏障”与终局“星核共鸣”。
- 军用模块路线：[PLACEHOLDER] 相位电容一枚，战斗开场增加30 MP；不与信赖80支援叠加。

所有数值均为待试玩假设，奖励只能结算一次。

任务收束：

> 弥珀：“我曾以为，只要没有离开，阿斯佩拉就不算结束。”  
> 凌霁：“离开不代表把它留下。”  
> 弥珀：“那就让我看看，记忆如何和活着的人一起航行。”

## 5. 后续主线回响

### 闻缄阶段

**条件：** trust 至少30，且闻缄尚未被击败。

- 镜后锚定中，弥珀指出一个“过分完美”的亡者伪声；玩家仍需自己完成原有 bracelet → memory → stars 序列。
- 信赖30：闻缄战首次控魂预警提前一回合显示。
- 信赖80：每次战斗尝试最多一次；凌霁连续失控一回合后，弥珀施放“反相屏障”，取消下一次失控，但不产生反击窗口。

台词：

> “这段回忆的频谱太完美了。他复制了声音，没复制人的迟疑。”

无弥珀支援时，原闻缄战仍必须可以通关。

### 岳沉戈阶段

**条件：** trust 为80，岳沉戈进入第二形态；每次终战尝试最多一次。

兽化岳沉戈首次准备“主炮共振”时，弥珀稳定星核频谱：

- 本次无法恢复护盾；
- 下一次“裂舰扑杀”路线提前显示；
- 不直接造成伤害。

> “我只能让星核不回应他一次。凌霁，剩下的由你回答。”

### 结局回响

- TRUE END：授衔演出前补充弥珀与岚禾坐在幸存者监督席前排；信赖80时，弥珀成为归潮号星核技术的共同管理者。
- 闻缄BE：不改现有《最后囚徒》CG，只在黑屏前追加：“阿斯佩拉共振频道最后一次查询LYRA-7。弥珀将记录标记为‘未完成’，而不是‘已失去’。”读档后不永久覆盖支线状态。

## 6. 失败、错过与旧存档

### 失败规则

- 校验或共振谜题答错：只复位当前操作并给具体提示。
- 中途返航：三项校验和共振节点进度保留。
- Boss战失败：每场一次的支援在重新挑战时恢复，不重做支线。
- 支线没有NPC死亡、永久降信赖或主线强制BE。

### 错过规则

- 完成余烬村后才发现弥珀：共振舱保持开放，可以补做。
- 击败闻缄后才完成支线：补充闻缄残留数据对话，但不追溯已经错过的战斗支援。
- 终局已开始但岳沉戈未败：可返回基地补做，再进入终局时生效。
- TRUE END已经看过：可完成“档案回看版”并解锁图鉴，不改写已播放结局。

### 旧存档迁移

旧存档缺少mi_po时补入默认值，不判坏档：

~~~gdscript
const MI_PO_DEFAULTS := {
    "met": false,
    "clock_restored": false,
    "pulse_verified": false,
    "memorial_returned": false,
    "trust": 0,
    "joined": false,
    "resonance_nodes": {},
    "archive_recovered": false,
    "shared_custody": false,
    "civilian_archive_first": false,
    "module_claimed": false,
    "quest_complete": false,
    "reward_claimed": false,
}
~~~

兼容规则：

- ruins.secret_recovered 已完成：共振舱和三项校验照常开放。
- ruins.clues 已包含 memorial：纪念塔仍可接收姓名片，不把旧调查误判为已归还。
- ruins.reported 已完成：允许补做，不扣信赖。
- pirate_arc.wen_defeated 已完成：只跳过闻缄机械支援。
- pirate_arc.yue_defeated 已完成：只播放档案回看收束。

读取时校验：

- trust 只允许0、30、80；
- trust达到30必须三项校验全部完成且joined为真；
- trust达到80必须archive_recovered、shared_custody和civilian_archive_first都为真；
- reward_claimed必须依赖quest_complete；
- resonance_nodes只接受 crater、observatory、vault 三个键及 positive、inverse、silent 三种值。

## 8. 代码接入规格

- game_state.gd

  - 提供幂等方法：meet_mi_po、complete_mi_po_check、set_resonance_node、resolve_mi_po_archive、complete_mi_po_quest。

  - ruined_village纪念塔支持姓名片交付；钻击坑与观测台支持后续共振节点。
  - 任务引导优先指向当前弥珀节点；玩家关闭支线追踪时仍显示余烬村主线。
- battle_screen.gd
  - 闻缄战读取trust，使用战斗局部“反相屏障未使用”标记。
  - 岳沉戈第二形态使用战斗局部“星核共鸣未使用”标记；每次setup重置，不写永久存档。
- finale.gd
  - 终战整备提示当前支援层级。
  - TRUE END追加监督席文本，不替换现有授衔CG。

## 9. 验收标准

- 未稳定避难所前不能启动弥珀支线。
- 三项校验任意顺序均可完成，错误不损失资源、不软锁。
- 姓名片必须由玩家亲自送至纪念墙，不能领取时自动结算。
- 信赖只有0、30、80，重复互动不累加、不回退。
- 无弥珀支援时闻缄和岳沉戈仍可通关。
- 旧存档处于余烬村已完成、闻缄已败、终局已完成三种情况时均有补叙路径。
- 奖励只结算一次，非法或矛盾状态不能通过读档校验。
- 弥珀在真结局中以幸存者和技术顾问身份出现，不是凌霁的附属或奖品。
