# 支线：《倒悬白渊》

版本：v0.2  
位置：赤晶祭坛 → 菌灯洞窟出口  
类型：撤离探索、陷阱解谜、心理恐怖、限时破局

## 内容边界与设计目标

凌霁为成年女性。支线中的“俘虏未来”只表现身份和行动自由被剥夺：完整着装、封闭围栏、编号管理和定时物资投放；不包含色情、裸露、身体侵犯、性暗示或羞辱式构图。

玩家先因连续识破现实陷阱建立信心，但每次选择安全绕路都会消耗时间，让祭祀的幻境逐渐成熟。随后玩家在空间翻转与身份幻象中感到不安，最终依靠此前观察到的线索主动打破幻境。

## 流程

```text
谈判失败，哥布林主动让路
  ↓
观察祭坛（可选：提前发现三裂眼符号）
  ↓
识破三处隐蔽的路线控制陷阱（风险、工具与时间取舍）
  ↓
出口错位，进入倒悬白渊
  ↓
看见“接受契约”的编号未来
  ↓
寻找形锚、声锚、名锚
  ↓
识别没有倒影的中心石针
  ├─ 现实稳定度归零 → BE-03「被安排的人生」
  └─ 击碎倒悬契印 → 回归现实，解锁重返祭坛
```

## 第一幕：礼貌的放行

谈判失败后，凌霁收起交换物资并主动终止交涉。祭祀没有围攻，反而让岩背守卫让开通道。

凌霁：

> “交易到此为止。我不会用自由换一把剑。”

祭祀：

> “门一直开着。能不能走出去，要看洞穴是否还认得你。”

凌霁：

> “洞穴不会记人。操纵洞穴的人才会。”

玩家可立即撤离，或观察祭坛。观察可发现祭祀法杖和石柱上的“三裂眼”，提前获得“锚点具有三重结构”线索。

## 第二幕：现实陷阱——它们要的不是命，是时间

这些机关不是摆在路面上的障碍，也不是等着主角逐个拆掉的解谜展品。哥布林把它们伪装成洞穴原有的泥地、菌丝、旧桥和矿道结构；凌霁依靠间接证据发现异常，但无法在第一眼看清完整机构。

陷阱对布置者而言没有“完全落空”的结果：误判会受伤或暴露位置，拆解会消耗工具与时间，绕路则会把凌霁推向更长的撤离路线。祭祀真正需要的是让她在洞穴里多停留一段时间，使倒悬契印完成同步。

三处机关共用一个隐藏数值 `镜境饱和度`，仅在后台记录，不直接显示百分比：

- 冒险走捷径：用HP和暴露风险换时间，后续幻境较弱。
- 原地拆解：消耗工具和中等时间，可额外取得机关线索。
- 观察后绕行：不受伤但耗时最多，后续幻境更完整、环境异常更明显。
- 找到隐蔽通道：需要较高感知或充分调查，同时保住HP与时间，是最佳结果。

无论饱和度高低，倒悬白渊都会作为剧情事件出现；数值只改变幻境强度、提示数量和首轮容错，避免玩家因为谨慎选择而遭遇毫无关联的强制失败。

### 捕兽夹

最短路线看起来只是铺着湿泥与菌毯的缓坡。捕兽夹几乎完全埋在淤泥和碎石下，玩家最多能看见一截暗淡齿尖；真正的提示是兽类足迹在同一点突然中断、水流绕开一块看似平整的泥地、菌丝朝向与自然生长方向相反。

- 冒险跨越：保住时间，但失败会损失 `[PLACEHOLDER 8%]` 当前HP并短暂迟缓。
- 原地拆解：消耗一件简易工具与少量时间，并发现第一滴逆重力镜质液。
- 攀爬绕行：不受伤，但消耗较多时间；在高处回望时可发现镜质残痕。
- 观察足迹后找到排水沟：安全快速通过，需要感知检定或此前调查洞穴生态。

凌霁：

> “不是为了杀我……它们在逼我按照某条路线走。”

### 绳索回声

最快的主通道看起来空旷安全，真正的触发物是一根混在垂根和雾气里的半透明菌丝。绳套、石袋和配重藏在钟乳石后的黑暗中；凌霁只能从岩钉的新鲜擦痕、顶部落尘形成的细线，以及铜铃不自然的静止角度推断出它们。

玩家可以冒险贴地穿过、花时间逆向追踪配重，或退入狭窄泥缝绕行。默认谨慎选择是绕行，不需要也不鼓励把整套机关拆掉。

若铜铃响起，幻境中的“追猎回声”频率提高，但不会召来现实敌人。铃声节拍之后成为声锚线索。

凌霁：

> “响铃不是警报，是节拍。祭祀在记录我的反应。”

### 地笼与木刺

最后一处机关伪装成废弃矿桥：压力木板混在旧板中，地笼收进顶部暗槽，木刺闸藏在覆苔墙板后，配重则伪装成桥梁承重结构。凌霁从一枚颜色过新的铁钉、顶部灰尘留下的方形暗影，以及三道磨损导槽汇向“三裂眼”刻痕判断出危险。

玩家可冒险通过旧桥、用工具确认并固定压力板，或转向陡峭的上层采矿路。安全绕行会让撤离再延迟一段时间，白色镜质矿液也从孤立液滴变成逆流而上的细线，明确提示某种仪式正在完成。

若机关被触发，地笼和木刺只负责分割路线与短暂困住角色，木刺不刺入身体；脱困后仍可继续剧情。

凌霁：

> “每条生路都更远。它们不是算错了，是在买时间。”

> “它不是想抓住我的身体……它想让我相信，服从才是唯一安全的选择。”

## 第三幕：倒悬白渊

临近出口时，门后传来海浪声。第一滴无机乳白色“零域镜质液”从地面向上坠落，空间像倒影一样翻转：

- 珠光白色液面铺在脚下，映出蓝天与云层；
- 岩地、道路、火把与赤晶悬在天空；
- 重力和WASD操作保持正常；
- 所有出口最终绕回原点。

祭祀的声音：

> “你拒绝的是一句话，不是已经发生的未来。”

凌霁：

> “未来不会因为被看见，就变成命令。”

镜质液是无机零域矿物，不具有生物来源。

## 第四幕：编号取代名字

凌霁看见另一个自己接受了契约：

- 姓名被抹去，只剩编号；
- 穿完整、宽松、耐用的哥布林劳作服；
- 武器、装甲和身份徽章锁在围栏外；
- 独自在整洁但封闭的观察围栏中；
- 食物、饮水和工具通过机械投放口定时送入。

镜像凌霁：

> “这里没有战斗，也没有选择。只要等下一次投放就好。”

玩家回应：

- `你不是我。`：提高自我锚定。
- `你为什么留下？`：镜像看向围栏外的身份徽章，获得名锚线索。
- `打碎围栏。`：围栏重组，但显露镜质液的流向。

## 第五幕：三重锚点

幻境由“倒悬契印”维持，包含三个部分：

1. **形锚**：悬在倒置岩层中的三裂眼石碑。
2. **声锚**：反复播放谈判中“接受”一词的回声。
3. **名锚**：围栏外被锁住的凌霁身份徽章。

玩家需要：

- 调整三面镜质液池，使石碑倒影重合；
- 按照现实陷阱中的铜铃节奏击碎错误回声；
- 取回身份徽章，并主动选择说出“凌霁”。

任意取得两条独立矛盾线索后，系统才标记真锚点：所有物体都有倒影，只有中央黑色石针在镜质液中没有倒影，且波纹始终从它向外扩散。

## 第六幕：击碎契印

倒悬契印每轮暴露 `[PLACEHOLDER 6秒]`。玩家需要闪避向天空坠落的岩块，连续破坏三层外壳；攻击镜像人物无效，并降低自我锚定。零域干扰类装备可以跳过一层外壳。

祭祀：

> “打碎它，你仍会回到那个需要不断战斗的世界。”

凌霁：

> “至少那是我自己选择的世界。”

> “我的名字是凌霁。我的路，由我决定。”

契印破裂后，镜质液像玻璃一样崩解。现实只过去数秒，凌霁仍站在出口前，但袖口沾着一滴逆重力镜质液。

## 结果与衔接

成功奖励：

- 解锁任务“重返赤晶祭坛”。
- 获得情报“镜质液样本”。
- 若三锚均靠观察破解，获得被动“现实校准”：小幅提高幻觉与恐惧抗性。
- 再次挑战祭祀时，可以跳过一次精神控制阶段。
- 本支线不会提前获得绝世宝剑，仍需完成战斗线。

### BE-03「被安排的人生」

自我锚定归零后，凌霁回到围栏幻象，姓名牌变为编号。画面停在她伸手看向围栏外身份徽章的瞬间，仍保留抵抗意志，随后读取幻境入口安全存档。

核心阶段HP归零时，凌霁在现实出口昏迷，醒来后被关在普通石牢，装备封存在可见柜内；不出现羞辱或身体侵犯。

软失败保护：

- 每次错误循环都会新增一道液流提示；
- 连续三次失败后，凌霁主动总结规律；
- 核心失败从幻境入口重试，无须重新通过现实陷阱。

## Godot最小接入设计

复用现有 `expedition.gd` 探索框架，不新建重复的探索控制器。

```gdscript
const GOBLIN_ARC_DEFAULTS := {
    "stage": 0,              # 0未开启 1陷阱撤离 2幻境 3已破除
    "trap_checkpoint": 0,    # 0入口 1捕兽夹后 2绳索后 3地笼后
    "mirror_clues": [],      # consent_log / ripple_source / missing_reflection
    "mirror_saturation": 0,  # 绕路与拆解耗时提高；影响幻境强度，不阻断主线
}
var goblin_arc: Dictionary = GOBLIN_ARC_DEFAULTS.duplicate(true)
```

临时陷阱预警、短暂定身、现实稳定度和BE播放状态不进存档。`mirror_clues.size() >= 2` 推导锚点显形，`stage == 3` 推导幻境已清除。

建议改动：

- `game_state.gd`：添加状态、存档迁移和场景恢复；兼容旧存档。
- `expedition_maps.gd`：添加 `goblin_depths`、`goblin_escape`、`goblin_mirror`。
- `expedition.gd`：添加三种陷阱交互、幻境线索、CG和任务提示。
- 新增 `cave_trap.gd`：可复用 `Area2D`，只发出类型化信号，由世界控制器统一处理伤害、回退和存档。

```gdscript
signal warning_started(trap_id: String)
signal warning_canceled(trap_id: String)
signal trap_triggered(trap_id: String, damage: int, return_position: Vector2)
signal trap_cleared(trap_id: String, checkpoint: int)
```

验收标准：三种陷阱只通过环境异常提示，不直接展示完整机构；每处至少有捷径、拆解、绕路和观察通道四类结果；绕路安全但会提高镜境饱和度；环境伤害最多降至1HP；已通过陷阱读档后不再封路；幻境不反转WASD；任意两条不同线索才显露锚点；重复线索不计数；BE不覆盖安全存档；破除后任务日志和地图出口恢复。

本文件只完成剧情、系统设计和CG规划，尚未修改游戏代码。
