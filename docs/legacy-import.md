## 旧版剧情与玩法备忘

### 封锁区 C9

- 新的高风险任务场景，用于放置多名敌人和陷阱。
- 怪物在地图上可见，具有巡逻、追击和伏击触发范围。
- 被伏击时敌人取得战斗先手；玩家从背后接近时可获得先手或首击加成。
- 可用陷阱：激光拌线、磁性地板、泡沫喷口和电击气体通风口。

### 失败与 BE 结局提案

- 普通失败：损失当前等级的部分 EXP，不立即删档。
- 只有 EXP 降到当前等级下限以下时才降级，并保留已获得的剧情关键物。
- 连续失败或污染值达到阈值时，可触发独立 BE 界面。
- BE 结局应保留“读取存档”与“返回据点”，不锁死玩家存档。
