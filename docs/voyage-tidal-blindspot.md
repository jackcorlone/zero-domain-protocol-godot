# 新章：《潮汐盲区》

版本：v0.1  
位置：ECHO-9任务汇报后、蚀日航母终章前  
类型：基地间歇、远征整备、生态探索、宇宙恐怖解谜、海洋撤离战

## 已有内容审查

项目已经有凌霁卧室背景 `assets/environments/lyra-bedroom-map-v1.png`，以及旧私人舱背景 `assets/environments/private-quarters-v1.png`。`docs/wen-jian-mirror-boss.md` 也已有发生在卧室的镜中入侵剧情。

但卧室目前只是背景和剧情素材，没有接入可行走地图、家具碰撞、门禁、存档点或换装。现有 `lyra-daily-portrait-v1.png` 是深蓝睡衣版本，不是本章需要的白衬衫与牛仔短裤，因此新增 `lyra-casual-shirt-denim-v1.png`，不覆盖旧素材。

## 章节流程

```text
凌霁卧室：收到失联信标、整理线索与装备
  ↓
H1星港候机环：查询航路、安检、选择支援模块
  ↓
潮根滩涂：避开或诱导触腕，发现人工神经晶片
  ↓
沉眠者回廊：调查零域认知遗迹，决定封锁方式
  ↓
裂潮海：在风暴甲板完成回收与撤离
  ↓
返回星港：根据救援、样本和遗迹选择结算
```

## 场景一：凌霁卧室

用途：章节安全屋和任务间歇。凌霁脱下战斗装，使用白色衬衫、蓝色牛仔短裤和白色室内运动鞋的休闲造型。

互动点：

- 床：休息并恢复生命与MP `[PLACEHOLDER]`。
- 个人终端：查看日志、任务与手动存档。
- 衣柜：查看日常装和战斗装；出发外勤时明确提示换回战斗装备。
- 战利品架：查看关键任务物品，不提供无限仓库。
- 门禁：检查访问记录，与既有闻缄镜中入侵和罗茂权限支线兼容。

本章入口：终端收到涅柔斯-4海洋观测队的失联信标。若玩家先完成频谱分析，可在星港提前识别“风暴并非自然形成”；跳过分析不会锁死主线。

## 场景二：H1星港候机环

它是基地的公开交通区，不等同于现有“游隼飞船舱”。场景包含候机大厅、安检闸门、货运扫描区、登舰口与极地停机坪。

互动点：

- 任务台：确认目的地、任务与可选支援。
- 安检门：对异常遗物给出风险说明，不无故没收玩家物品。
- 航务官贺岑：在风暴绝缘模块与额外MP电池之间选择一项 `[PLACEHOLDER]`。
- 检疫官祁雾：分析异星生态样本，并制作抗黏附喷剂。
- 航路终端：确认失联信号来自海洋行星涅柔斯-4。
- 登舰口：进入游隼号并锁定本章外勤存档。

正常状态下没有战斗。警报状态可使用“小型零域寄生体”作为触腕机制教学，但需先制作对应怪物立绘和战斗数据。

## 场景三：潮根滩涂

定位：非色情的异星触腕生态。触腕是会感知震动的装甲根系/深海生物共生体，负责守护巢区和人工共振柱。

探索互动：

- 投掷碎石制造震动，将触腕引向错误方向。
- 关闭三枚共振柱，延长安全移动窗口。
- 切断根节打开捷径，但提高区域警戒。
- 观察水面波纹，判断下一处钻出点。
- 采集抗黏附药材，制作一次性挣脱道具。

敌人：普通怪“潮须潜根”“孢囊漂体”，精英怪“根冠母体”。触腕攻击只表现拉拽、击退和束缚判定；挣脱失败损失耐力并回到岸边锚点，不表现情色或身体羞辱。

剧情输出：凌霁在根冠组织内发现人工神经晶片，证明触腕生态正被海底零域遗迹控制。

## 场景四：沉眠者回廊

定位：原创宇宙恐怖遗迹，不直接复制具体克苏鲁角色。古代海洋文明曾试图把群体意识上传零域，“古神低语”实际是跨时代残留认知。

探索互动：

- 旋转非欧几里得门框，让原本不相邻的墙面短暂连通。
- 比对三种声纹，识别真正通向核心的门。
- 关闭低语降低失真度，或承受干扰寻找隐藏房间。
- 在核心选择关闭、重定向或保留风暴封锁。

敌人：普通怪“潮印侍从”“无面观测体”，精英怪“逆谱合唱体”。`失真度` 只改变地图表现、敌人配置和提示清晰度；满值触发短暂镜像战并返回安全锚点，不制造不可预期的永久坏结局。

## 场景五：裂潮海

场景发生在游隼号海洋任务模块的开放甲板。巨浪会周期性冲刷甲板，闪电、锚索和移动货箱共同组成战斗机制。

战斗互动：

- 观察三段浪向，提前进入绝缘掩体。
- 操作甲板锚机，固定货物或短暂限制大型敌人。
- 闪电蓄积时躲避，或把导电标记引向海兽。
- 落水不会立即死亡，安全索会拉回角色，但损失一个输出窗口。
- 救援科研员、保护完整样本、追击首领三项不能同时完成，形成任务取舍。

敌人：普通怪“裂鳍猎兽”“引雷水母”，精英怪“深潮脊兽”。

遗迹选择影响终战：

- 关闭封锁：风暴减弱，但隐藏探索区永久关闭。
- 重定向封锁：Boss强化，胜利后保留探索区。
- 保留封锁：先撤退，日后携带专用防护装备重返。

## Godot最小接入方案

本轮尚未修改场景脚本。实现时遵守以下边界：

1. 卧室复用 `scenes/exploration.tscn` 和 `scripts/exploration.gd` 的动态场景框架，新增 `quarters` 地点、家具碰撞以及 `door/bed/desk/wardrobe/terminal` 互动点。
2. 卧室背景原始尺寸为1672×941，接入1280×720探索视口前需要沿用现有裁切/缩放方式；全身立绘不能直接充当行走帧。
3. 星港与三张外勤地图复用 `expedition.gd`、`expedition_maps.gd`，均按1536×1024配置出生点、障碍和互动点。
4. 新地点不能直接写入现有 `echo.visited`。新增独立 `voyage` 存档段与 `VOYAGE_LOCATIONS`。
5. 建议初始状态：

```gdscript
const VOYAGE_DEFAULTS := {
    "accepted": false,
    "visited": [],
    "starport_clearance": false,
    "tentacle_core_destroyed": false,
    "ruin_seal_state": "", # closed / redirected / preserved
    "storm_boss_defeated": false,
    "outcome": "",
}
```

6. 只换战斗背景不够。`battle_screen.gd` 当前按 `encounter_id` 硬编码敌人名称、HP、倍率和胜利处理；三类战场接入前必须补怪物立绘、encounter数据和胜利状态。
7. 测试至少覆盖：卧室保存恢复、星港登舰、四张新地图可达性、三种遗迹选择、三场战斗胜负推进以及旧存档迁移。
